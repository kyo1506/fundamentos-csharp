# 03.2: Delegates, Func, Action, Lambdas e Closures

> **Fase 03: Coleções Avançadas, Delegados, Eventos, Generics e LINQ** · Aula 2
> Objetivo: compreender o funcionamento de ponteiros de função com type-safety através de delegates, dominar os delegates pré-definidos `Action` e `Func`, escrever lambdas expressivas e entender o mecanismo de closures e captura de variáveis.

---

## 1. O que é um Delegate?

Um **delegate** é um tipo por referência que encapsula a assinatura e o endereço de um ou mais métodos. Ele permite passar métodos como argumentos para outros métodos, viabilizando programação de ordem superior e callbacks:

```csharp
// Declaração tradicional de delegate:
public delegate decimal OperacaoMatematica(decimal x, decimal y);

public class Calculadora
{
    public static decimal Executar(decimal a, decimal b, OperacaoMatematica op) => op(a, b);
}

// Uso:
decimal Somar(decimal x, decimal y) => x + y;
OperacaoMatematica operacao = Somar;
var resultado = Calculadora.Executar(10m, 20m, operacao); // 30
```

## 2. Os Delegates Padrão: `Action`, `Func` e `Predicate`

Na grande maioria dos casos modernos, você não precisa declarar delegates customizados com a palavra-chave `delegate`. O .NET já fornece tipos genéricos prontos no namespace `System`:

### `Action<T1, T2, ...>` (Não retorna valor: `void`)
Usado quando você deseja executar uma ação com efeitos colaterais sem retornar nada:
```csharp
Action<string> log = mensagem => Console.WriteLine($"[LOG]: {mensagem}");
Action<string, int> exibirRepeticoes = (txt, n) =>
{
    for (int i = 0; i < n; i++) Console.WriteLine(txt);
};
```

### `Func<T1, T2, ..., TResult>` (Sempre retorna valor `TResult`)
O último parâmetro genérico é sempre o tipo de retorno:
```csharp
Func<int, int, int> multiplicar = (a, b) => a * b;
Func<string, int> obterTamanho = texto => texto.Length;
Func<decimal, decimal, decimal> calcularDesconto = (valor, taxa) => valor * taxa;
```

### `Predicate<T>` (Retorna `bool`)
Equivalente a `Func<T, bool>`, usado historicamente em buscas de listas (`List<T>.FindAll`):
```csharp
Predicate<int> ehPositivo = n => n > 0;
```

## 3. Expressões Lambda

Uma **expressão lambda** é uma forma anônima e concisa de escrever uma função inline usando o operador `=>`:

```csharp
// Sintaxe com corpo de expressão (expression body):
Func<int, int> dobrar = x => x * 2;

// Sintaxe com bloco de comandos (statement body):
Func<int, int, int> maior = (a, b) =>
{
    if (a > b) return a;
    return b;
};
```

## 4. Closures e Captura de Variáveis

Uma **closure** ocorre quando uma expressão lambda referencia uma variável local declarada fora do seu escopo imediato (escopo pai). O compilador do C# gera uma classe oculta em background para manter a variável viva mesmo após o método pai ter sido concluído:

```csharp
public static Func<int, int> CriarMultiplicador(int fator)
{
    // A variável 'fator' é capturada pela closure:
    return numero => numero * fator;
}

var triplicar = CriarMultiplicador(3);
Console.WriteLine(triplicar(10)); // 30
```

### Armadilha Clássica de Captura em Laços
Em versões antigas do C#, capturar uma variável de controle de laço causava surpresas. No C# moderno, cada iteração de um `foreach` gera uma nova variável local, mas em laços `for` clássicos ainda deve-se ter cautela ao capturar o índice se a execução for adiada:

```csharp
var acoes = new List<Action>();
for (int i = 0; i < 3; i++)
{
    int capturado = i; // Crie uma cópia local por iteração!
    acoes.Add(() => Console.WriteLine(capturado));
}

foreach (var a in acoes) a(); // Imprime 0, 1, 2
```
