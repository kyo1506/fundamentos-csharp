## 1. O Contrato `IEnumerable<T>` e a Máquina de Estados do C#

No coração de todas as coleções e consultas LINQ está a interface `IEnumerable<T>`:

```csharp
public interface IEnumerable<out T> : IEnumerable
{
    IEnumerator<T> GetEnumerator();
}

public interface IEnumerator<out T> : IDisposable, IEnumerator
{
    T Current { get; }
    bool MoveNext();
    void Reset();
}
```

Quando você escreve um `foreach`, o compilador traduz seu código para:
```csharp
using var enumerator = colecao.GetEnumerator();
while (enumerator.MoveNext())
{
    var item = enumerator.Current;
    // seu bloco de código aqui
}
```

## 2. Iteradores Personalizados com `yield return` e `yield break`

A instrução `yield return` permite produzir elementos **sob demanda**, sob medida que o consumidor solicita, sem precisar criar e armazenar listas gigantescas na memória:

```csharp
public static class Geradores
{
    // Gera números pares até o limite especificado sem pré-alocar array:
    public static IEnumerable<int> ObterPares(int limite)
    {
        for (int i = 0; i <= limite; i++)
        {
            if (i % 2 == 0)
                yield return i; // Pausa o método e devolve o item para quem chamou!
        }
    }

    // Leitura preguiçosa de linhas de um arquivo:
    public static IEnumerable<string> LerLinhas(string caminho)
    {
        using var reader = File.OpenText(caminho);
        string? linha;
        while ((linha = reader.ReadLine()) is not null)
        {
            if (linha.StartsWith("#")) continue; // Ignora comentários
            yield return linha;
        }
    }
}
```

### `yield break`
Interrompe a sequência imediatamente, simulando o fim do fluxo de dados:

```csharp
public static IEnumerable<int> ContarAteDez()
{
    int i = 1;
    while (true)
    {
        if (i > 10) yield break; // Encerra a iteração
        yield return i++;
    }
}
```

## 3. Coleções Especializadas da BCL

### `PriorityQueue<TElement, TPriority>` (.NET 6+)
Estrutura de dados baseada em Heap binário (fila de prioridade). O elemento de menor valor de prioridade é sempre desenfileirado primeiro:

```csharp
var filaAtendimento = new PriorityQueue<string, int>();

// Adiciona itens com prioridade (1 = altíssima, 3 = normal)
filaAtendimento.Enqueue("Dúvida simples no fórum", 3);
filaAtendimento.Enqueue("Bug crítico no pagamento de matrícula", 1);
filaAtendimento.Enqueue("Solicitação de alteração de e-mail", 2);

// Desenfileira sempre por ordem de prioridade:
while (filaAtendimento.TryDequeue(out var tarefa, out var prioridade))
{
    Console.WriteLine($"[Prioridade {prioridade}]: {tarefa}");
}
// Saída:
// [Prioridade 1]: Bug crítico no pagamento de matrícula
// [Prioridade 2]: Solicitação de alteração de e-mail
// [Prioridade 3]: Dúvida simples no fórum
```

### Coleções Imutáveis (`System.Collections.Immutable`)
Ao contrário de `ReadOnlyCollection` (que é apenas uma casca sobre uma lista mutável subjacente), coleções imutáveis **nunca mudam**. Cada adição ou remoção produz uma nova referência estruturalmente compartilhada com máxima eficiência:

```csharp
using System.Collections.Immutable;

var listaOriginal = ImmutableList.Create("C#", "F#");
var novaLista = listaOriginal.Add("TypeScript");

Console.WriteLine(listaOriginal.Count); // 2
Console.WriteLine(novaLista.Count);     // 3
```
