# 03.4: LINQ: Fundamentos, Sintaxe Fluente e Execução Adiada (Deferred Execution)

> **Fase 03: Coleções Avançadas, Delegados, Eventos, Generics e LINQ** · Aula 4
> Objetivo: dominar o Language Integrated Query (LINQ), entender a diferença entre sintaxe de consulta (query syntax) e sintaxe de método fluente, e dominar o conceito crítico de execução adiada vs execução imediata.

---

## 1. O que é LINQ?

LINQ (Language Integrated Query) unifica a manipulação de dados em coleções em memória (`IEnumerable<T>`), bancos de dados relacionais (`IQueryable<T>` via EF Core), XML e JSON em uma sintaxe declarativa e fortemente tipada.

### Duas Sintaxes Disponíveis
1. **Query Syntax (SQL-like):**
```csharp
var resultado = from c in cursos
                where c.PrecoBase > 500m
                orderby c.Titulo
                select c.Titulo;
```

2. **Method Syntax / Fluent API (Predileção da indústria):**
```csharp
var resultado = cursos
    .Where(c => c.PrecoBase > 500m)
    .OrderBy(c => c.Titulo)
    .Select(c => c.Titulo);
```
A sintaxe de método oferece suporte total a todos os operadores do LINQ (alguns operadores, como `Take` ou `Distinct`, não possuem palavras-chave equivalentes na query syntax).

---

## 2. Operadores Fundamentais de Filtragem e Projeção

- `Where`: filtra elementos com base em um predicado booleano (`Func<T, bool>`).
- `Select`: projeta e transforma cada elemento em um novo formato (`Func<T, TResult>`).
- `SelectMany`: achata (flatten) coleções aninhadas em uma única sequência plana.
- `OrderBy` / `OrderByDescending`: ordena por chave de ordenação.
- `ThenBy` / `ThenByDescending`: aplica critérios secundários de ordenação.
- `Distinct` / `DistinctBy`: remove duplicatas.

```csharp
var titulos = cursos
    .Where(c => c.Nivel == NivelCurso.Avancado)
    .OrderByDescending(c => c.PrecoBase)
    .ThenBy(c => c.Titulo)
    .Select(c => c.Titulo);
```

---

## 3. O Conceito Crucial: Execução Adiada (Deferred Execution)

Muitos métodos de extensão do LINQ (`Where`, `Select`, `Take`) **não executam a consulta no momento em que são declarados**. Eles apenas constroem um plano de iteração (uma árvore de iteradores):

```csharp
var numeros = new List<int> { 1, 2, 3 };

// A consulta é apenas construída, nada foi filtrado ainda!
var maioresQueDois = numeros.Where(n => n > 2);

// Adicionamos um novo número à lista original:
numeros.Add(4);

// A consulta SÓ EXECUTA agora que iteramos com foreach:
foreach (var n in maioresQueDois)
{
    Console.WriteLine(n); // Imprime 3 E 4!
}
```

---

## 4. Forçando Execução Imediata (Materialização)

Para forçar a execução imediata e guardar uma fotografia dos dados em memória, utilize operadores de materialização:

- `.ToList()`: converte a sequência em `List<T>`.
- `.ToArray()`: converte em array primitivo `T[]`.
- `.ToDictionary(...)`: indexa em `Dictionary<TKey, TValue>`.
- Operadores escalares que retornam um único valor: `.Count()`, `.Sum()`, `.Average()`, `.First()`, `.FirstOrDefault()`, `.Any()`, `.All()`.

```csharp
// Execução imediata garantida:
var listaFixa = numeros.Where(n => n > 2).ToList();
numeros.Add(99); // Não afeta 'listaFixa'
```

---

## 5. Armadilha: Múltipla Enumeração (Multiple Enumeration)

Se você declarar uma consulta adiada e consumi-la várias vezes (ex.: chamar `.Count()` e depois fazer um `foreach`), **a consulta inteira será reexecutada do início duas vezes**:

```csharp
// Anti-exemplo:
IEnumerable<Aluno> aprovados = ConsultarBancoOuFiltrar();
if (aprovados.Any()) // Executa 1 vez
{
    foreach (var a in aprovados) // Executa uma segunda vez!
    {
        Console.WriteLine(a.Nome);
    }
}

// Exemplo correto: materialize uma única vez quando for reutilizar:
var listaAprovados = ConsultarBancoOuFiltrar().ToList();
if (listaAprovados.Count > 0)
{
    foreach (var a in listaAprovados) Console.WriteLine(a.Nome);
}
```
