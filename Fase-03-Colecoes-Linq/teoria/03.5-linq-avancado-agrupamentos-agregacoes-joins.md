# 03.5: LINQ Avançado: Agrupamentos, Agregações, Joins e Particionamento

> Objetivo: dominar operadores avançados de análise de dados com LINQ, incluindo `GroupBy`, junções com `Join`, cálculos acumulativos com `Aggregate`, particionamento com `Chunk`/`Take`/`Skip` e projeções em records anônimos ou fortemente tipados.

## 1. Agrupamento com `GroupBy`

O operador `GroupBy` particiona a sequência em grupos (`IGrouping<TKey, TElement>`), onde cada grupo possui uma chave (`Key`) e se comporta como uma coleção contendo os itens associados:

```csharp
// Agrupando matrículas pelo Nível do Curso associado:
var matriculasPorNivel = matriculas
    .GroupBy(m => m.Curso.Nivel);

foreach (var grupo in matriculasPorNivel)
{
    Console.WriteLine($"\nNível: {grupo.Key} (Total de matrículas: {grupo.Count()})");
    foreach (var mat in grupo)
    {
        Console.WriteLine($" - {mat.Aluno.Nome}: R$ {mat.ValorCobrado:N2}");
    }
}
```

Podemos também projetar diretamente um relatório agrupado em DTO/Record:

```csharp
public record ResumoNivel(NivelCurso Nivel, int TotalMatriculas, decimal ReceitaTotal);

var relatorio = matriculas
    .GroupBy(m => m.Curso.Nivel)
    .Select(g => new ResumoNivel(
        Nivel: g.Key,
        TotalMatriculas: g.Count(),
        ReceitaTotal: g.Sum(m => m.ValorCobrado)
    ))
    .OrderByDescending(r => r.ReceitaTotal)
    .ToList();
```

## 2. Agregações Customizadas com `Aggregate`

Além das agregações prontas (`Sum`, `Average`, `Min`, `Max`, `Count`), o operador `Aggregate` permite implementar acumuladores arbitrários:

```csharp
// Exemplo: formatar lista de títulos de cursos separados por vírgula com Aggregate:
var titulos = cursos.Select(c => c.Titulo);
var formatado = titulos.Aggregate((acumulador, proximo) => $"{acumulador}, {proximo}");

// Exemplo: calcular receita líquida aplicando descontos e taxas acumuladas com semente (seed):
decimal saldoInicial = 1000m;
var saldoFinal = matriculas.Aggregate(saldoInicial, (total, m) => total + m.ValorCobrado);
```

## 3. Junção de Coleções com `Join`

O operador `Join` correlaciona duas sequências independentes com base em chaves coincidentes (semelhante ao `INNER JOIN` do SQL):

```csharp
public record Pagamento(Guid MatriculaId, string Metodo, decimal Valor);

var pagamentosConfirmados = matriculas.Join(
    pagamentos,
    mat => mat.Id,          // Chave da coleção externa
    pag => pag.MatriculaId, // Chave da coleção interna
    (mat, pag) => new
    {
        Aluno = mat.Aluno.Nome,
        Curso = mat.Curso.Titulo,
        Forma = pag.Metodo,
        Valor = pag.Valor
    }
);
```

## 4. Particionamento e Paginação: `Skip`, `Take` e `Chunk`

Operações essenciais para APIs REST e paginação no front-end:

```csharp
int pagina = 2;
int tamanhoPagina = 5;

var itensPagina = cursos
    .OrderBy(c => c.Titulo)
    .Skip((pagina - 1) * tamanhoPagina)
    .Take(tamanhoPagina)
    .ToList();
```

### O Operador `Chunk` (.NET 6+)
Divide uma coleção em blocos (fatias) de tamanho fixo:

```csharp
var lotes = cursos.Chunk(3); // Cada lote é um array de até 3 cursos
foreach (var lote in lotes)
{
    Console.WriteLine($"Processando lote com {lote.Length} cursos...");
}
```

## 5. Operadores de Busca Segura: `First` vs `FirstOrDefault` vs `Single`

| Operador | 0 elementos encontrados | 1 elemento encontrado | >1 elementos encontrados |
|---|---|---|---|
| `First()` | Lança `InvalidOperationException` | Retorna o elemento | Retorna o primeiro elemento |
| `FirstOrDefault()` | Retorna `null` ou `default(T)` | Retorna o elemento | Retorna o primeiro elemento |
| `Single()` | Lança `InvalidOperationException` | Retorna o elemento | Lança `InvalidOperationException` |
| `SingleOrDefault()` | Retorna `null` ou `default(T)` | Retorna o elemento | Lança `InvalidOperationException` |

> Regra: use `SingleOrDefault` quando a existência de mais de um registro indicar inconsistência grave no banco ou domínio (ex.: busca por documento único ou Id).
