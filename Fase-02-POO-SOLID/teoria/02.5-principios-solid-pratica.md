# 02.5: Os Princípios SOLID na Prática (com Exemplos e Anti-exemplos)

> **Fase 02: Programação Orientada a Objetos + SOLID** · Aula 5
> Objetivo: dominar cada um dos 5 princípios SOLID formulados por Robert C. Martin (Uncle Bob), identificando code smells de violação e aplicando refatorações idiomáticas em C#.

---

## 1. Visão Geral do SOLID

| Letra | Princípio | Ideia Central |
|---|---|---|
| **S** | Single Responsibility Principle (SRP) | Uma classe deve ter um, e apenas um, motivo para mudar. |
| **O** | Open/Closed Principle (OCP) | Aberto para extensão, fechado para modificação. |
| **L** | Liskov Substitution Principle (LSP) | Subclasses devem ser substituíveis por suas classes base sem quebrar o sistema. |
| **I** | Interface Segregation Principle (ISP) | Nenhuma classe deve ser forçada a depender de métodos que não usa. |
| **D** | Dependency Inversion Principle (DIP) | Módulos de alto nível não devem depender de módulos de baixo nível; ambos devem depender de abstrações. |

---

## 2. SRP: Princípio da Responsabilidade Única

> *"A class should have one, and only one, reason to change."*

### Anti-exemplo: Classe "Deus" (God Class)
```csharp
public class Fatura
{
    public decimal Valor { get; set; }

    public void SalvarNoBancoDeDados() { /* SQL direto aqui */ }
    public void ImprimirRelatorioPdf() { /* Renderização gráfica */ }
    public void EnviarEmailCobranca() { /* Protocolo SMTP */ }
}
// Essa classe muda se o banco mudar, se o layout do PDF mudar ou se o provedor de e-mail mudar!
```

### Exemplo Correto: Responsabilidades Separadas
```csharp
public class Fatura(Guid id, decimal valor)
{
    public Guid Id { get; } = id;
    public decimal Valor { get; } = valor;
}

public class FaturaRepositorio
{
    public void Salvar(Fatura fatura) { /* Apenas persistência */ }
}

public class FaturaNotificador
{
    public void NotificarCliente(Fatura fatura) { /* Apenas comunicação */ }
}
```

## 3. OCP: Princípio Aberto/Fechado

> *"Software entities should be open for extension, but closed for modification."*

### Anti-exemplo: Switch Crescente e Frágil
```csharp
public class CalculadorDesconto
{
    public decimal Calcular(string tipoCliente, decimal valor) => tipoCliente switch
    {
        "Comum" => valor * 0.05m,
        "Premium" => valor * 0.15m,
        "Vip" => valor * 0.25m,
        _ => 0m
    };
}
// Cada novo tipo de cliente exige abrir e editar este arquivo, arriscando quebrar os clientes existentes.
```

### Exemplo Correto: Extensão por Polimorfismo / Strategy
```csharp
public interface IRegraDesconto
{
    decimal CalcularDesconto(decimal valor);
}

public class DescontoComum : IRegraDesconto
{
    public decimal CalcularDesconto(decimal valor) => valor * 0.05m;
}

public class DescontoPremium : IRegraDesconto
{
    public decimal CalcularDesconto(decimal valor) => valor * 0.15m;
}

// Para adicionar "DescontoBlackFriday", criamos uma nova classe sem tocar no código antigo!
```

## 4. LSP: Princípio da Substituição de Liskov

> *"Subtypes must be substitutable for their base types without altering correctness."*

### Anti-exemplo Clássico: Retângulo vs Quadrado ou Pássaro que não voa
```csharp
public class Passaro
{
    public virtual void Voar() => Console.WriteLine("Voando alto...");
}

public class Pinguim : Passaro
{
    public override void Voar()
    {
        // Violação gritante de LSP! Quebra a expectativa de quem chama Passaro.Voar()
        throw new NotSupportedException("Pinguins não voam!");
    }
}
```

### Exemplo Correto: Hierarquias Sem Falsas Promessas
```csharp
public abstract class Passaro(string especie)
{
    public string Especie { get; } = especie;
}

public interface IAveVoadora
{
    void Voar();
}

public class Gaviao : Passaro, IAveVoadora
{
    public Gaviao() : base("Gavião") {}
    public void Voar() => Console.WriteLine("Gavião voando.");
}

public class Pinguim : Passaro
{
    public Pinguim() : base("Pinguim") {}
    public void Nadar() => Console.WriteLine("Pinguim nadando com maestria.");
}
```

## 5. ISP: Princípio da Segregação de Interfaces

> *"Clients should not be forced to depend upon interfaces that they do not use."*

### Anti-exemplo: Interface "Gorda"
```csharp
public interface IDispositivoMultifuncional
{
    void Imprimir(string doc);
    void Escanear(string doc);
    void EnviarFax(string doc);
}

// Uma impressora simples não tem Fax nem Scanner:
public class ImpressoraEconomica : IDispositivoMultifuncional
{
    public void Imprimir(string doc) => Console.WriteLine("Imprimindo...");
    public void Escanear(string doc) => throw new NotImplementedException();
    public void EnviarFax(string doc) => throw new NotImplementedException();
}
```

### Exemplo Correto: Interfaces Pequenas e Coesas
```csharp
public interface IImpressora { void Imprimir(string doc); }
public interface IScanner { void Escanear(string doc); }
public interface IFax { void EnviarFax(string doc); }

public class ImpressoraSimples : IImpressora
{
    public void Imprimir(string doc) => Console.WriteLine("Imprimindo com agilidade.");
}

public class MegaMultifuncional : IImpressora, IScanner, IFax
{
    public void Imprimir(string doc) { /* ... */ }
    public void Escanear(string doc) { /* ... */ }
    public void EnviarFax(string doc) { /* ... */ }
}
```

## 6. DIP: Princípio da Inversão de Dependência

> *"High-level modules should not depend on low-level modules. Both should depend on abstractions."*

### Anti-exemplo: Acoplamento Concreto com `new`
```csharp
public class SqlServerDatabase
{
    public void GravarLog(string texto) => Console.WriteLine($"SQL: {texto}");
}

public class ProcessadorFinanceiro
{
    private readonly SqlServerDatabase _db = new(); // Dependência acoplada e impossível de mockar!

    public void Processar(decimal valor)
    {
        _db.GravarLog($"Processando {valor}");
    }
}
```

### Exemplo Correto: Inversão com Abstração
```csharp
public interface IRegistroLog
{
    void Gravar(string mensagem);
}

public class SqlServerLog : IRegistroLog
{
    public void Gravar(string mensagem) => Console.WriteLine($"SQL: {mensagem}");
}

public class ProcessadorFinanceiro(IRegistroLog log)
{
    public void Processar(decimal valor)
    {
        log.Gravar($"Processando {valor}");
    }
}
```
