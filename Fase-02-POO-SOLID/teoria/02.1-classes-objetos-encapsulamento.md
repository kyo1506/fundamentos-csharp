## 1. O que é uma Classe e um Objeto

Em C#, uma **classe** é a planta ou modelo (blueprint) que define a estrutura de dados (campos, propriedades) e o comportamento (métodos, eventos) de um tipo. Um **objeto** é a instância concreta dessa classe alocada na memória Heap:

```csharp
// Declaração de uma classe com Primary Constructor (C# 12+)
public class ContaBancaria(string titular, decimal saldoInicial = 0m)
{
    public string Titular { get; } = titular;
    public decimal Saldo { get; private set; } = saldoInicial;

    public void Depositar(decimal valor)
    {
        if (valor <= 0)
            throw new ArgumentOutOfRangeException(nameof(valor), "O valor do depósito deve ser positivo.");

        Saldo += valor;
    }
}
```

Instanciação:

```csharp
var conta = new ContaBancaria("Ana Costa", 500m);
conta.Depositar(150m);
Console.WriteLine($"Saldo atual: {conta.Saldo}"); // 650
```

## 2. Encapsulamento: Ocultar Detalhes e Proteger Invariantes

Encapsulamento é a prática de agrupar dados e comportamentos relacionados, restringindo o acesso direto ao estado interno do objeto para garantir que ele permaneça sempre em um estado válido (invariante de domínio).

### Anti-exemplo: Estado Exposto Sem Proteção
```csharp
public class PedidoRuim
{
    public decimal ValorTotal; // Qualquer código pode alterar para negativo!
    public string Status;      // Pode receber texto inválido como "batata"
}
```

### Exemplo Correto: Encapsulamento com Validação
```csharp
public class Pedido
{
    private readonly List<ItemPedido> _itens = new();

    public IReadOnlyCollection<ItemPedido> Itens => _itens.AsReadOnly();
    public decimal Total => _itens.Sum(i => i.Subtotal);

    public void AdicionarItem(ItemPedido item)
    {
        ArgumentNullException.ThrowIfNull(item);
        _itens.Add(item);
    }
}
```

## 3. Modificadores de Acesso em C#

| Modificador | Onde é acessível |
|---|---|
| `public` | Acessível por qualquer código no mesmo assembly ou em outros assemblies referenciados |
| `private` | Acessível apenas dentro do corpo da própria classe/struct |
| `protected` | Acessível na própria classe e em classes derivadas dela |
| `internal` | Acessível por qualquer código dentro do mesmo assembly (.dll/.exe) |
| `protected internal` | Acessível no mesmo assembly OU em classes derivadas em outros assemblies |
| `private protected` | Acessível em classes derivadas, mas APENAS dentro do mesmo assembly |
| `file` (C# 11+) | Acessível exclusivamente no mesmo arquivo de código-fonte |

## 4. Propriedades Modernas: Init-only, Expressões e Validação

### Propriedades com Backing Field Explícito
```csharp
public class Aluno
{
    private string _email = string.Empty;

    public required string Nome { get; init; }

    public string Email
    {
        get => _email;
        set
        {
            if (string.IsNullOrWhiteSpace(value) || !value.Contains('@'))
                throw new ArgumentException("E-mail inválido.", nameof(value));
            _email = value.Trim().ToLowerInvariant();
        }
    }
}
```

### O Modificador `init`
Introduzido no C# 9, permite que a propriedade seja atribuída apenas durante a inicialização do objeto (via construtor ou inicializador de objeto `{ }`), tornando o objeto imutável após a criação:

```csharp
var aluno = new Aluno { Nome = "Carlos", Email = "carlos@escola.com" };
// aluno.Nome = "Outro"; // Erro de compilação: propriedade init-only
```

## 5. Resumo e Boas Práticas
- Torne campos `private` e exponha propriedades com visibilidade mínima necessária (`private set` ou `init`).
- Proteja coleções internas retornando `IReadOnlyCollection<T>` ou `IReadOnlyList<T>`.
- Use primary constructors para injeção de dependência e propriedades imutáveis concisas.
- Lance exceções apropriadas (`ArgumentException`, `InvalidOperationException`) caso uma operação viole as regras de negócio.
