## 1. O que é Polimorfismo

Polimorfismo (do grego "muitas formas") é o princípio que permite tratar objetos de tipos diferentes por meio de uma interface ou classe base comum, invocando o comportamento apropriado em tempo de execução sem conhecer a classe concreta subjacente.

### Duas Formas de Polimorfismo
1. **Polimorfismo em Tempo de Compilação (Estático):** sobrecarga de métodos (method overloading) e tipos genéricos.
2. **Polimorfismo em Tempo de Execução (Dinâmico):** classes abstratas/virtuais e interfaces usando despacho dinâmico.

## 2. Interfaces em C#

Uma **interface** define um contrato estrito de comportamento (o que deve ser feito), sem ditar como os dados internos devem ser organizados ou mantidos.

Uma classe ou struct pode implementar **múltiplas interfaces**:

```csharp
public interface IValidador<in T>
{
    bool Validar(T item, out string mensagemErro);
}

public interface IExportavel
{
    string ExportarFormatoTexto();
}

public class MatriculaAluno(string codigo, string nomeAluno, decimal valor) : IExportavel
{
    public string Codigo { get; } = codigo;
    public string NomeAluno { get; } = nomeAluno;
    public decimal Valor { get; } = valor;

    public string ExportarFormatoTexto() =>
        $"MATRICULA|{Codigo}|{NomeAluno}|{Valor:F2}";
}
```

## 3. Polimorfismo na Prática

Imagine um processador de pagamentos que não precisa saber se o pagamento é via Pix, Cartão ou Boleto:

```csharp
public interface IMetodoPagamento
{
    string Nome { get; }
    decimal CalcularTaxa(decimal valor);
    bool Processar(decimal valor);
}

public class PagamentoPix : IMetodoPagamento
{
    public string Nome => "Pix";
    public decimal CalcularTaxa(decimal valor) => 0m; // Sem taxa
    public bool Processar(decimal valor)
    {
        Console.WriteLine($"Pix instantâneo no valor de R$ {valor:N2} aprovado.");
        return true;
    }
}

public class PagamentoCartaoCredito : IMetodoPagamento
{
    public string Nome => "Cartão de Crédito";
    public decimal CalcularTaxa(decimal valor) => valor * 0.03m; // 3% taxa
    public bool Processar(decimal valor)
    {
        var taxa = CalcularTaxa(valor);
        Console.WriteLine($"Cartão processado: R$ {valor:N2} (Taxa: R$ {taxa:N2}).");
        return true;
    }
}
```

O consumidor depende **apenas da interface**:

```csharp
public class CaixaRegistradora
{
    public void FinalizarVenda(decimal total, IMetodoPagamento metodo)
    {
        var taxa = metodo.CalcularTaxa(total);
        var totalComTaxa = total + taxa;

        Console.WriteLine($"Cobrando via {metodo.Nome}: R$ {totalComTaxa:N2}");
        metodo.Processar(totalComTaxa);
    }
}
```

## 4. Implementação Explícita de Interfaces

Quando uma classe implementa duas interfaces que possuem membros com assinaturas idênticas, ou quando desejamos que certos membros não apareçam na API pública direta da classe, usamos **implementação explícita**:

```csharp
public interface IRelatorioTexto
{
    void Imprimir();
}

public interface IRelatorioPdf
{
    void Imprimir();
}

public class DocumentoFiscal : IRelatorioTexto, IRelatorioPdf
{
    void IRelatorioTexto.Imprimir() => Console.WriteLine("Imprimindo texto no console...");

    void IRelatorioPdf.Imprimir() => Console.WriteLine("Gerando stream binário PDF...");
}

// Uso:
var doc = new DocumentoFiscal();
// doc.Imprimir(); // Erro de compilação! O método não existe diretamente em doc.

((IRelatorioTexto)doc).Imprimir(); // Imprime texto
((IRelatorioPdf)doc).Imprimir();   // Imprime PDF
```

## 5. Classes Abstratas vs Interfaces: Quando Usar Cada Uma?

| Critério | Classe Abstrata | Interface |
|---|---|---|
| **Herança** | Simples (uma única classe base) | Múltipla (implementa $N$ interfaces) |
| **Identidade** | Relação "É UM" (core identity) | Relação "PODE FAZER" (capability) |
| **Estado** | Pode conter campos de instância, estado e construtores | Não contém campos de instância (apenas contratos) |
| **Uso ideal** | Compartilhar código e base comum entre tipos fortemente correlacionados | Desacoplar camadas, criar plugins, facilitar testes unitários com mocks/fakes |
