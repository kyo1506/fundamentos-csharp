# Lição 05.3: Injeção de Dependência com Microsoft.Extensions

Injeção de Dependência (DI) é a implementação técnica do princípio de Inversão de Controle (IoC). No ecossistema .NET moderno, o pacote `Microsoft.Extensions.DependencyInjection` fornece um contêiner nativo, altamente performático e padronizado em todas as ferramentas da plataforma.

---

## 1. O Contêiner de Inversão de Controle: IServiceCollection e IServiceProvider

O processo de injeção de dependência divide-se em duas etapas estritas:
1. **Configuração (Registro):** Declarar os contratos e suas respectivas implementações no `IServiceCollection`.
2. **Resolução (Consumo):** Obter instâncias através do `IServiceProvider` (ou automaticamente por injeção no construtor).

```csharp
using Microsoft.Extensions.DependencyInjection;

// 1. Cria a coleção de serviços
var services = new ServiceCollection();

// 2. Registra os tipos e ciclos de vida
services.AddTransient<IPoliticaDesconto, DescontoPromocional>();
services.AddScoped<ICursoRepository, InMemoryCursoRepository>();
services.AddSingleton<TimeProvider>(TimeProvider.System);

// 3. Constrói o provedor de serviços
using ServiceProvider provider = services.BuildServiceProvider();

// 4. Resolve o serviço desejado
var repositorio = provider.GetRequiredService<ICursoRepository>();
```

---

## 2. Ciclos de Vida (Lifetimes)

O contêiner gerencia quando as instâncias são criadas e quando são descartadas via `IDisposable`.

| Ciclo de Vida | Método de Registro | Comportamento | Casos de Uso Recomendados |
|---|---|---|---|
| **Transient** | `AddTransient<TInterface, TImpl>()` | Uma nova instância é criada a cada resolução ou injeção. | Serviços leves e sem estado (ex: validadores, formatadores, calculadoras puras). |
| **Scoped** | `AddScoped<TInterface, TImpl>()` | Uma única instância por escopo (`IServiceScope`). | Contextos de banco de dados (`DbContext`), repositórios, serviços de domínio em requisições web. |
| **Singleton** | `AddSingleton<TInterface, TImpl>()` | Criado apenas na primeira solicitação e reutilizado durante toda a vida do processo. | Caches em memória, clientes HTTP reutilizáveis, configurações imutáveis, instâncias de `TimeProvider`. |

## 3. Escopos Explícitos com IServiceScopeFactory

Em aplicações de console, background workers ou filas de mensagens assíncronas, você precisa criar escopos manualmente para delimitar o ciclo de vida de serviços `Scoped`:

```csharp
public async Task ProcessarFilaAsync(IServiceProvider rootProvider)
{
    // Cria um escopo isolado
    using (IServiceScope scope = rootProvider.CreateScope())
    {
        // Resolve um serviço Scoped dentro deste escopo
        var repo = scope.ServiceProvider.GetRequiredService<ICursoRepository>();
        await repo.AdicionarAsync(new Curso(1, "Microsserviços"));
    } // Ao sair do bloco using, todos os serviços IDisposable criados no escopo são liberados
}
```

## 4. O Erro da Dependência Cativa (Captive Dependency)

Um dos erros mais perigosos em arquitetura .NET ocorre quando um serviço de vida longa consome um serviço de vida curta:
- **Exemplo Crítico:** Injetar um serviço `Scoped` (como um `DbContext`) dentro de um serviço `Singleton`.
- **Consequência:** O serviço `Scoped` fica retido na memória indefinidamente enquanto o `Singleton` estiver vivo. Isso provoca vazamento de memória e concorrência indevida entre threads.

O contêiner do .NET detecta isso automaticamente em ambiente de desenvolvimento quando configurado:

```csharp
var provider = services.BuildServiceProvider(new ServiceProviderOptions
{
    ValidateScopes = true,       // Valida se serviços Scoped estão sendo resolvidos na raiz Singleton
    ValidateOnBuild = true       // Valida se todas as dependências registradas conseguem ser resolvidas
});
```

## 5. Boas Práticas: Métodos de Extensão de Registro

Nunca polua o arquivo `Program.cs` com dezenas de linhas de registro soltas. Encapsule o registro das dependências em métodos de extensão organizados por camada:

```csharp
public static class DependencyInjectionExtensions
{
    public static IServiceCollection AddDomainServices(this IServiceCollection services)
    {
        services.AddScoped<ICursoService, CursoService>();
        services.AddTransient<IPoliticaDesconto, DescontoPromocional>();
        return services;
    }

    public static IServiceCollection AddInfrastructureServices(this IServiceCollection services)
    {
        services.AddScoped<ICursoRepository, InMemoryCursoRepository>();
        return services;
    }
}
```

No `Program.cs`:
```csharp
var services = new ServiceCollection();
services
    .AddDomainServices()
    .AddInfrastructureServices();
```
