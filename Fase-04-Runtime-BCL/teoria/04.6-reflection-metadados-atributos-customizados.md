# Lição 04.6: Reflection, Metadados e Atributos Customizados

O Common Language Runtime (CLR) do .NET armazena metadados descritivos completos de cada tipo, método, propriedade e parâmetro compilado nos assemblies. **Reflection** é o mecanismo que permite inspecionar, descobrir e invocar dinamicamente esses elementos em tempo de execução.

---

## 1. Obtendo Metadados com System.Type

A porta de entrada para Reflection é a classe `Type`:

```csharp
// Forma 1: Em tempo de compilação via operador typeof
Type tipo1 = typeof(string);

// Forma 2: Em tempo de execução a partir de uma instância
object objeto = 100.5m;
Type tipo2 = objeto.GetType();

Console.WriteLine($"Nome do Tipo: {tipo2.Name}");
Console.WriteLine($"Namespace: {tipo2.Namespace}");
Console.WriteLine($"É Tipo de Valor: {tipo2.IsValueType}");
```

### Inspecionando Propriedades e Métodos

```csharp
using System.Reflection;

Type tipo = typeof(Aluno);

// Listar propriedades públicas
PropertyInfo[] propriedades = tipo.GetProperties(BindingFlags.Public | BindingFlags.Instance);
foreach (var prop in propriedades)
{
    Console.WriteLine($"Propriedade: {prop.Name} ({prop.PropertyType.Name})");
}

// Ler o valor de uma propriedade dinamicamente
var aluno = new Aluno { Nome = "Carlos" };
PropertyInfo? propNome = tipo.GetProperty("Nome");
object? valor = propNome?.GetValue(aluno);
Console.WriteLine($"Valor lido via reflection: {valor}");
```

## 2. Criando e Aplicando Atributos Customizados

Atributos são classes que herdam de `System.Attribute` e decoram outros elementos com metadados declarativos.

### Definindo um Atributo

```csharp
[AttributeUsage(AttributeTargets.Property | AttributeTargets.Class, AllowMultiple = false)]
public class ColunaRelatorioAttribute : Attribute
{
    public string Cabecalho { get; }
    public int Ordem { get; }

    public ColunaRelatorioAttribute(string cabecalho, int ordem = 0)
    {
        Cabecalho = cabecalho;
        Ordem = ordem;
    }
}
```

### Decorando Classes de Domínio

```csharp
public class CursoRelatorioDto
{
    [ColunaRelatorio("Identificador", ordem: 1)]
    public int Codigo { get; set; }

    [ColunaRelatorio("Título do Curso", ordem: 2)]
    public string Titulo { get; set; } = string.Empty;

    [ColunaRelatorio("Preço Base (BRL)", ordem: 3)]
    public decimal Preco { get; set; }

    // Propriedade sem atributo (não entra no relatório)
    public string HashInterno { get; set; } = string.Empty;
}
```

## 3. Lendo Atributos em Tempo de Execução

Podemos criar geradores de relatórios genéricos que leem a decoração dos objetos:

```csharp
public static class ExportadorCsvReflectivo
{
    public static string GerarCabecalho<T>()
    {
        var props = typeof(T).GetProperties()
            .Select(p => new
            {
                Prop = p,
                Attr = p.GetCustomAttribute<ColunaRelatorioAttribute>()
            })
            .Where(x => x.Attr != null)
            .OrderBy(x => x.Attr!.Ordem)
            .Select(x => x.Attr!.Cabecalho);

        return string.Join(";", props);
    }

    public static string GerarLinha<T>(T item)
    {
        var valores = typeof(T).GetProperties()
            .Select(p => new
            {
                Prop = p,
                Attr = p.GetCustomAttribute<ColunaRelatorioAttribute>()
            })
            .Where(x => x.Attr != null)
            .OrderBy(x => x.Attr!.Ordem)
            .Select(x => x.Prop.GetValue(item)?.ToString() ?? string.Empty);

        return string.Join(";", valores);
    }
}
```

## 4. O Custo de Desempenho e Boas Práticas

Reflection é uma ferramenta muito poderosa, mas possui desvantagens claras:

1. **Custo de CPU:** A busca de metadados em tabelas de assembly envolve busca por strings e checagens de segurança. Executar `GetProperties()` milhares de vezes dentro de um laço reduz drasticamente a velocidade da aplicação.
2. **Incompatibilidade com Trim/AOT:** Compiladores Ahead-of-Time podem remover propriedades e tipos que parecem nunca ser chamados no código estático, quebrando Reflection em runtime.
3. **Cache de Reflection:** Se você precisa de reflection dinâmico, faça cache dos `PropertyInfo` ou compile delegates com `Expression.Compile()` ou `Emit` para executar em velocidade nativa.

```csharp
// Exemplo de cache simples de propriedades
public static class ReflectionCache<T>
{
    public static readonly PropertyInfo[] Propriedades = typeof(T).GetProperties();
}
```
