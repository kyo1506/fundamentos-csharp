# Lição 04.3: Serialização com System.Text.Json e Source Generators

O namespace `System.Text.Json` é o mecanismo padrão de serialização do .NET moderno. Projetado com foco em altíssima performance, ele é construído sobre `Span<byte>`, `Utf8JsonReader` e `Utf8JsonWriter`, minimizando alocações de memória e suportando compilação AOT (Ahead-of-Time).

---

## 1. Serialização Básica e JsonSerializerOptions

A forma mais comum de converter objetos em JSON e vice-versa é através da classe estática `JsonSerializer`:

```csharp
using System.Text.Json;
using System.Text.Json.Serialization;

public record AlunoDto(int Id, string Nome, string Email, decimal Media);

var aluno = new AlunoDto(1, "Ana Silva", "ana@exemplo.com", 9.5m);

var opcoes = new JsonSerializerOptions
{
    WriteIndented = true, // Formatação legível (pretty print)
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase, // "nome" em vez de "Nome"
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull
};

// Serializar para string
string json = JsonSerializer.Serialize(aluno, opcoes);
Console.WriteLine(json);

// Desserializar de string
AlunoDto? deserializado = JsonSerializer.Deserialize<AlunoDto>(json, opcoes);
```

## 2. Serialização Direta com Streams (Zero Cópia Intermediária)

Evite serializar para `string` quando o destino for um arquivo em disco ou resposta HTTP. A leitura e escrita direta via `Stream` assíncrono economiza alocações massivas de strings temporárias:

```csharp
public async Task SalvarEmArquivoAsync<T>(string caminho, T dados, JsonSerializerOptions opcoes)
{
    await using var stream = File.Create(caminho);
    await JsonSerializer.SerializeAsync(stream, dados, opcoes);
}

public async Task<T?> CarregarDeArquivoAsync<T>(string caminho, JsonSerializerOptions opcoes)
{
    await using var stream = File.OpenRead(caminho);
    return await JsonSerializer.DeserializeAsync<T>(stream, opcoes);
}
```

### Streaming Contínuo com IAsyncEnumerable

Para arquivos com milhares de objetos em formato de array JSON `[ {...}, {...} ]`, podemos consumir item a item via streaming sem carregar todo o array em memória:

```csharp
public async Task ProcessarStreamingJsonAsync(Stream streamJson)
{
    IAsyncEnumerable<AlunoDto?> alunosStream = JsonSerializer.DeserializeAsyncEnumerable<AlunoDto>(streamJson);

    await foreach (AlunoDto? aluno in alunosStream)
    {
        if (aluno != null)
        {
            Console.WriteLine($"Recebido via stream: {aluno.Nome}");
        }
    }
}
```

## 3. Conversor Customizado (JsonConverter<T>)

Quando tipos específicos possuem formato de serialização não padrão (por exemplo, datas formatadas de forma legada ou valores monetários como string com símbolo), implementamos um `JsonConverter<T>`:

```csharp
public class DateOnlyJsonConverter : JsonConverter<DateOnly>
{
    private const string Formato = "yyyy-MM-dd";

    public override DateOnly Read(ref Utf8JsonReader reader, Type typeToConvert, JsonSerializerOptions options)
    {
        string? texto = reader.GetString();
        return DateOnly.ParseExact(texto!, Formato);
    }

    public override void Write(Utf8JsonWriter writer, DateOnly value, JsonSerializerOptions options)
    {
        writer.WriteStringValue(value.ToString(Formato));
    }
}
```

## 4. Source Generators para System.Text.Json

Por padrão, `JsonSerializer` usa reflexão em tempo de execução para inspecionar propriedades das classes. No entanto, em microsserviços modernos, contêineres mínimos e aplicações Native AOT, a reflexão:
1. Impõe lentidão na primeira inicialização (cold start).
2. Não pode ser otimizada por tree-shaking do compilador.
3. Aloca metadados dinâmicos na memória.

Com os **Source Generators** do C#, o compilador gera o código de serialização diretamente durante o build:

```csharp
[JsonSerializable(typeof(AlunoDto))]
[JsonSerializable(typeof(List<AlunoDto>))]
public partial class AppJsonSerializerContext : JsonSerializerContext
{
}
```

### Usando o Contexto Gerado

```csharp
// Serialização ultra-rápida sem reflexão
string jsonAot = JsonSerializer.Serialize(aluno, AppJsonSerializerContext.Default.AlunoDto);

// Desserialização segura para AOT
AlunoDto? resultado = JsonSerializer.Deserialize(jsonAot, AppJsonSerializerContext.Default.AlunoDto);
```

### Vantagens do Source Generator
- **Zero Reflection:** Compatível com Native AOT do .NET.
- **Inicialização Instantânea:** Sem custo de inspeção de propriedades em runtime.
- **Validação em Tempo de Compilação:** Erros de tipos suportados são detectados antes de rodar o programa.
