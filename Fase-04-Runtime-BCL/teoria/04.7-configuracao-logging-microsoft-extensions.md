# Lição 04.7: Configuração e Logging com Microsoft.Extensions

O ecossistema `Microsoft.Extensions` padroniza os blocos construtivos essenciais de qualquer aplicação .NET corporativa, incluindo microsserviços, consoles, workers e APIs web. O sistema de configuração e a biblioteca de logging estruturado são dois desses pilares fundamentais.

---

## 1. Configuração Hierárquica com IConfiguration

A interface `IConfiguration` abstrai origens heterogêneas de configuração em uma árvore única de chave-valor. O leitor avalia fontes em ordem de prioridade:
1. Arquivos JSON padrão (`appsettings.json`).
2. Arquivos de ambiente (`appsettings.Development.json` ou `appsettings.Production.json`).
3. Variáveis de ambiente do sistema operacional (úteis em contêineres Docker/Kubernetes).
4. Argumentos de linha de comando (`--chave valor`).

### Exemplo de Arquivo appsettings.json

```json
{
  "Processamento": {
    "DiretorioEntrada": "./dados",
    "MaximoConcorrencia": 4,
    "TimeoutSegundos": 30
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft": "Warning"
    }
  }
}
```

### Construindo o IConfiguration no Console

```csharp
using Microsoft.Extensions.Configuration;

var builder = new ConfigurationBuilder()
    .SetBasePath(Directory.GetCurrentDirectory())
    .AddJsonFile("appsettings.json", optional: true, reloadOnChange: true)
    .AddEnvironmentVariables(prefix: "APP_")
    .AddCommandLine(args);

IConfiguration config = builder.Build();

// Leitura simples
int concorrencia = config.GetValue<int>("Processamento:MaximoConcorrencia", defaultValue: 2);
string diretorio = config["Processamento:DiretorioEntrada"] ?? "./dados";
```

### O Padrão Options (Tipagem Forte)

Em vez de espalhar strings mágicas como `"Processamento:MaximoConcorrencia"`, mapeamos seções para classes C#:

```csharp
public class ConfiguracoesProcessamento
{
    public string DiretorioEntrada { get; set; } = "./dados";
    public int MaximoConcorrencia { get; set; } = 2;
    public int TimeoutSegundos { get; set; } = 30;
}

// Vinculação automática (Binding)
var opcoes = new ConfiguracoesProcessamento();
config.GetSection("Processamento").Bind(opcoes);
```

## 2. Logging Estruturado com ILogger

O .NET moderno não utiliza concatenação de texto bruto em logs (`Console.WriteLine("Erro no item " + id)`). O logging moderno é **estruturado**: as propriedades passadas na mensagem são preservadas como dados semânticos indexáveis em ferramentas de observabilidade (como OpenTelemetry, Elasticsearch, Datadog ou Azure Application Insights).

### Configurando uma LoggerFactory

```csharp
using Microsoft.Extensions.Logging;

using ILoggerFactory factory = LoggerFactory.Create(builder =>
{
    builder
        .AddConsole()
        .SetMinimumLevel(LogLevel.Debug);
});

ILogger logger = factory.CreateLogger<Program>();
```

### A Forma Correta de Registrar Logs Estruturados

Passe os parâmetros como argumentos posicionais do template de mensagem, sem usar interpolação direta com `$`:

```csharp
// ERRADO (destrói as métricas estruturadas e aloca strings extras desnecessárias):
logger.LogInformation($"Processando aluno {alunoId} no curso {cursoId}");

// CORRETO (Logging Estruturado com placeholders nomeados):
logger.LogInformation("Processando aluno {AlunoId} no curso {CursoId}", alunoId, cursoId);
```

### Níveis de Log (LogLevel)

| Nível | Finalidade |
|---|---|
| `Trace` | Detalhamento extremo para diagnóstico minucioso em desenvolvimento local. |
| `Debug` | Informações úteis durante depuração de regras de negócio. |
| `Information` | Eventos normais do fluxo de vida da aplicação (início de lote, conclusão de relatório). |
| `Warning` | Situações anormais recuperáveis (ex: tentativa de reconexão, formato inesperado ignorado). |
| `Error` | Falhas que impedem a execução de uma operação específica (ex: arquivo não encontrado). |
| `Critical` | Falhas catastróficas que exigem intervenção imediata ou encerram a aplicação. |

## 3. Escopos de Log (Scopes)

Escopos permitem anexar propriedades contextuais comuns a todas as mensagens emitidas dentro de um bloco de execução:

```csharp
using (logger.BeginScope("Lote: {LoteId}, Origem: {Origem}", loteId, "IngestaoMatriculas"))
{
    logger.LogInformation("Iniciando processamento...");
    // Todas as linhas emitidas aqui carregarão automaticamente LoteId e Origem
    logger.LogInformation("Processamento finalizado com sucesso.");
}
```
