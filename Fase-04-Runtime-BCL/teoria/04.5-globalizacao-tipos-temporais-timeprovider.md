# Lição 04.5: Globalização, Tipos Temporais e TimeProvider

A manipulação de datas, horas, números e fusos horários em aplicações distribuídas requer rigor técnico. Erros de formatação cultural (como vírgula versus ponto decimal) e confusões entre UTC e horário local são fontes clássicas de bugs críticos em produção.

---

## 1. Tipos Temporais no .NET Moderno

O .NET disponibiliza estruturas específicas para cada semântica temporal:

| Tipo | Semântica | Quando Usar |
|---|---|---|
| `DateTime` | Instante com `Kind` flexível (Utc, Local, Unspecified). | Código legado. Evitar em novos domínios por causa de ambiguidade de fuso. |
| `DateTimeOffset` | Ponto inequívoco na linha do tempo com deslocamento explícito em relação a UTC. | Carimbos de data/hora globais, logs de eventos, APIs REST. |
| `DateOnly` | Apenas ano, mês e dia (sem componente de horário ou fuso). | Aniversários, datas de emissão de notas fiscais, datas de corte. |
| `TimeOnly` | Apenas horas, minutos, segundos e milissegundos. | Horário de abertura de lojas, agendamento de rotinas diárias. |
| `TimeSpan` | Duração ou intervalo de tempo decorrido. | Medição de latência, timeouts, cálculo de intervalos. |

### Exemplo de Uso Moderno

```csharp
// Data de nascimento não possui fuso horário
DateOnly nascimento = new DateOnly(1995, 8, 20);

// Horário comercial fixo diário
TimeOnly inicioExpediente = new TimeOnly(9, 0, 0);

// Instante global de auditoria
DateTimeOffset registroUtc = DateTimeOffset.UtcNow;
```

## 2. Fusos Horários com TimeZoneInfo

Para converter instantes globais para fusos específicos de usuários ou localidades:

```csharp
DateTimeOffset agoraUtc = DateTimeOffset.UtcNow;

// Fuso horário de Brasília
TimeZoneInfo fusoBrasilia = TimeZoneInfo.FindSystemTimeZoneById("E. South America Standard Time");
// No Linux/macOS: "America/Sao_Paulo"

DateTimeOffset agoraBrasilia = TimeZoneInfo.ConvertTime(agoraUtc, fusoBrasilia);
Console.WriteLine($"Horário em Brasília: {agoraBrasilia:dd/MM/yyyy HH:mm:ss zzz}");
```

## 3. Globalização e CultureInfo

A representação de números, moedas e datas varia drasticamente por país. No Brasil, decimais usam vírgula (`12,50`); nos Estados Unidos, usam ponto (`12.50`).

### Cultura da Máquina vs. Cultura Invariante

- `CultureInfo.CurrentCulture`: Usa a cultura regional configurada no sistema operacional. Útil apenas para exibir textos diretamente na tela para o usuário final humano.
- `CultureInfo.InvariantCulture`: Cultura neutra baseada no padrão americano (ponto como separador decimal, formato de data ISO). **Obrigatório para arquivos de dados, logs, payloads JSON, CSV e comunicação entre serviços.**

```csharp
using System.Globalization;

decimal preco = 1250.75m;

// Para salvar em arquivo texto ou CSV (sempre invariante)
string csvLinha = preco.ToString("F2", CultureInfo.InvariantCulture); // "1250.75"

// Para exibir para um usuário em português
string exibicaoBr = preco.ToString("C", new CultureInfo("pt-BR")); // "R$ 1.250,75"

// Parse seguro com invariância
decimal recuperado = decimal.Parse("1250.75", CultureInfo.InvariantCulture);
```

## 4. Testabilidade Temporal com TimeProvider

Antes do .NET 8, era muito difícil testar regras de negócio dependentes do tempo (como expiração de tokens após 2 horas ou cobrança de juros após 30 dias), pois o código chamava diretamente `DateTime.UtcNow` ou `DateTimeOffset.UtcNow`.

O .NET 8 introduziu a classe abstrata `TimeProvider`, que permite abstrair o relógio do sistema:

```csharp
public class GerenciadorSessao
{
    private readonly TimeProvider _timeProvider;

    public GerenciadorSessao(TimeProvider? timeProvider = null)
    {
        // Se não for fornecido nos testes, usa o relógio real do sistema
        _timeProvider = timeProvider ?? TimeProvider.System;
    }

    public DateTimeOffset CriarExpiracao(TimeSpan validade)
    {
        return _timeProvider.GetUtcNow().Add(validade);
    }

    public bool EstaExpirado(DateTimeOffset dataExpiracao)
    {
        return _timeProvider.GetUtcNow() > dataExpiracao;
    }
}
```

### Criando um TimeProvider Falso para Testes Unitários

Em testes, podemos avançar ou congelar o tempo instantaneamente sem usar `Thread.Sleep`:

```csharp
public class FakeTimeProvider : TimeProvider
{
    private DateTimeOffset _horaAtual;

    public FakeTimeProvider(DateTimeOffset horaInicial)
    {
        _horaAtual = horaInicial;
    }

    public override DateTimeOffset GetUtcNow() => _horaAtual;

    public void AvancarTempo(TimeSpan duracao)
    {
        _horaAtual = _horaAtual.Add(duracao);
    }
}
```

No teste xUnit:

```csharp
[Fact]
public void Deve_Identificar_Sessao_Expirada()
{
    var inicio = new DateTimeOffset(2026, 10, 1, 10, 0, 0, TimeSpan.Zero);
    var fakeTime = new FakeTimeProvider(inicio);

    var gestor = new GerenciadorSessao(fakeTime);
    var expiracao = gestor.CriarExpiracao(TimeSpan.FromMinutes(30));

    // Antes do tempo: não expirado
    Assert.False(gestor.EstaExpirado(expiracao));

    // Avança 31 minutos instantaneamente
    fakeTime.AvancarTempo(TimeSpan.FromMinutes(31));

    // Agora deve estar expirado
    Assert.True(gestor.EstaExpirado(expiracao));
}
```
