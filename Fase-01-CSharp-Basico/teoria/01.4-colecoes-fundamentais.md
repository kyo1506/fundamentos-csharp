## 1. Visão Geral e Complexidade Assintótica

Escolher a coleção errada pode transformar um algoritmo $O(1)$ em $O(N)$ ou $O(N^2)$:

| Coleção | Acesso por Chave/Índice | Busca por Valor | Inserção | Remoção | Cenário Ideal |
|---|---|---|---|---|---|
| `T[]` (Array) | $O(1)$ | $O(N)$ | N/A (fixo) | N/A | Tamanho imutável e conhecido a priori |
| `List<T>` | $O(1)$ (por índice) | $O(N)$ | $O(1)$ amortizado | $O(N)$ | Lista sequencial genérica indexada |
| `Dictionary<TKey, TValue>` | $O(1)$ médio | $O(N)$ | $O(1)$ médio | $O(1)$ médio | Mapeamento chave-valor unívoco |
| `HashSet<T>` | N/A | $O(1)$ médio | $O(1)$ médio | $O(1)$ médio | Unicidade e testes rápidos de pertinência |
| `Queue<T>` | N/A | $O(N)$ | $O(1)$ (Enqueue) | $O(1)$ (Dequeue) | Processamento sequencial FIFO (Fila) |
| `Stack<T>` | N/A | $O(N)$ | $O(1)$ (Push) | $O(1)$ (Pop) | Histórico / Desfazer LIFO (Pilha) |

## 2. `List<T>` em Profundidade: Crescimento Interno

`List<T>` encapsula um array interno `T[]`. Quando a quantidade de elementos excede a `Capacity`:
1. Um novo array com o **dobro da capacidade** é alocado na Heap.
2. Todos os elementos existentes são copiados para o novo array.
3. O array antigo fica para o Garbage Collector coletar.

```csharp
// ❌ Provoca múltiplas realocações de array (capacidade cresce: 0 -> 4 -> 8 -> 16 -> 32...)
List<int> lista = new();
for (int i = 0; i < 1000; i++) lista.Add(i);

// ✅ Se souber o tamanho aproximado, defina a capacidade inicial:
List<int> listaOtimizada = new(capacity: 1000); // 1 única alocação
```

## 3. `Dictionary<TKey, TValue>`: Tabelas Hash no CLR

Utiliza o código hash (`GetHashCode()`) da chave para calcular o índice do bucket correspondente.

```csharp
var precos = new Dictionary<string, decimal>(StringComparer.OrdinalIgnoreCase)
{
    ["CAF-01"] = 4.50m,
    ["CHA-02"] = 3.80m
};

// Acesso seguro (evita KeyNotFoundException):
if (precos.TryGetValue("CAF-01", out decimal preco))
{
    Console.WriteLine($"Preço: {preco:C}");
}

// Atualização ou inserção atômica:
precos["PAO-03"] = 1.20m;
```

## 4. `HashSet<T>`: Conjuntos Matemáticos e Alta Velocidade

Garante que não há duplicatas e permite operações matemáticas de conjuntos em $O(N)$:

```csharp
var permitidos = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "ADMIN", "EDITOR" };

if (permitidos.Contains("admin")) // O(1) imediato
{
    Console.WriteLine("Acesso concedido");
}

var conjuntoA = new HashSet<int> { 1, 2, 3, 4 };
var conjuntoB = new HashSet<int> { 3, 4, 5, 6 };

// Interseção: { 3, 4 }
conjuntoA.IntersectWith(conjuntoB);

// União: { 1, 2, 3, 4, 5, 6 }
// conjuntoA.UnionWith(conjuntoB);
```

## 5. `Queue<T>` (FIFO) e `Stack<T>` (LIFO)

```csharp
// Fila (First In, First Out)
var filaAtendimento = new Queue<string>();
filaAtendimento.Enqueue("Cliente 1");
filaAtendimento.Enqueue("Cliente 2");

string atendido = filaAtendimento.Dequeue(); // "Cliente 1"
string proximo = filaAtendimento.Peek();      // "Cliente 2" (sem remover)

// Pilha (Last In, First Out)
var historicoUndo = new Stack<string>();
historicoUndo.Push("Texto inicial");
historicoUndo.Push("Texto modificado");

string desfeito = historicoUndo.Pop(); // "Texto modificado"
```
