# 01.10 — `DateTime`, `DateTimeOffset`, `DateOnly`, `TimeOnly` e `TimeSpan`

> **Fase 01 — C# Básico: a linguagem em profundidade** · Aula 10
> Objetivo: dominar a manipulação de tempo no .NET moderno, entendendo as armadilhas de fuso horário em DateTime, por que DateTimeOffset é o padrão para auditoria e APIs, e como utilizar DateOnly/TimeOnly e aritmética com TimeSpan.

---

## 1. A Evolução do Tempo no .NET

| Tipo | O que armazena | Quando usar |
|---|---|---|
| `DateTime` | Data + Hora + `DateTimeKind` (Utc, Local, Unspecified) | Legado ou cálculos puramente locais sem fuso horário |
| `DateTimeOffset` | Data + Hora + **Deslocamento UTC explícito** (ex.: `-03:00`) | **Padrão recomendado para bancos, logs, auditoria e APIs REST** |
| `DateOnly` (C# 10 / .NET 6+) | Apenas ano, mês e dia (sem hora nem fuso) | Datas comemorativas, aniversários, datas de vencimento de boletos |
| `TimeOnly` (C# 10 / .NET 6+) | Apenas hora, minuto, segundo, milissegundo | Horário de abertura de loja, alarmes diários |
| `TimeSpan` | Intervalo/duração de tempo | Medição de latência, tempo decorrido, tempos limites (timeouts) |

---

## 2. A Armadilha Clássica do `DateTime.Now` vs `DateTime.UtcNow`

```csharp
// ❌ Problemático em servidores distribuídos ou cloud (depende da timezone do servidor)
DateTime agoraLocal = DateTime.Now;

// ✅ Consistente e inequívoco em qualquer lugar do mundo:
DateTimeOffset agoraUtc = DateTimeOffset.UtcNow;
Console.WriteLine(agoraUtc.ToString("o")); // Formato padrão ISO-8601: 2026-09-21T10:05:00.0000000Z
```

Converter para o fuso do usuário (ex.: Horário de Brasília / `-03:00`):

```csharp
var fusoBrasilia = TimeZoneInfo.FindSystemTimeZoneById(
    OperatingSystem.IsWindows() ? "E. South America Standard Time" : "America/Sao_Paulo");

DateTimeOffset emBrasilia = TimeZoneInfo.ConvertTime(agoraUtc, fusoBrasilia);
Console.WriteLine($"Brasília: {emBrasilia:dd/MM/yyyy HH:mm:ss zzz}");
```

---

## 3. Tipos Modernos: `DateOnly` e `TimeOnly`

Evita o clássico bug de salvar uma data de nascimento com horário `00:00:00` e ter o dia deslocado devido a fusos horários:

```csharp
DateOnly aniversario = new DateOnly(1995, 5, 14);
TimeOnly inicioExpediente = new TimeOnly(9, 0);

Console.WriteLine($"Aniversário: {aniversario:dd/MM/yyyy}"); // 14/05/1995
Console.WriteLine($"Abertura: {inicioExpediente:HH:mm}");      // 09:00
```

---

## 4. Aritmética e Duração com `TimeSpan`

```csharp
DateTime inicio = DateTime.UtcNow;
// ... operação ...
DateTime fim = DateTime.UtcNow;

TimeSpan duracao = fim - inicio;
Console.WriteLine($"Tempo decorrido: {duracao.TotalMilliseconds:N2} ms");

// Operações de soma e subtração:
DateTimeOffset vencimento = DateTimeOffset.UtcNow.AddDays(30);
TimeSpan intervaloTimeout = TimeSpan.FromSeconds(45);
```

**Médio — 2.** Escreva um método `CalcularDiasUteis(DateOnly inicio, DateOnly fim)` que itera entre as datas e retorna apenas a quantidade de dias úteis (segunda a sexta-feira).

**Desafiador — 3.** Escreva um método que recebe uma string no formato ISO-8601 e a converte para o horário local de Brasília, tratando exceções de parsing e exibindo no formato amigável `"21 de setembro de 2026 às 14h30 (GMT-03:00)"`.
