# 01.9 — Classes e Métodos de Extensão

> **Fase 01 — C# Básico: a linguagem em profundidade** · Aula 9
> Objetivo: dominar a criação de métodos de extensão no C#, entender como o compilador resolve chamadas encadeadas, regras de prioridade sobre métodos de instância e tratamento seguro de nulos.

---

## 1. O que são Métodos de Extensão?

Métodos de extensão permitem adicionar novos métodos a tipos existentes (incluindo classes seladas, interfaces e tipos da BCL como `string`, `int`, `IEnumerable<T>`) **sem modificar o código-fonte original ou criar herança**:

- Devem ser declarados dentro de uma **classe estática não-aninhada** (`static class`).
- O primeiro parâmetro deve obrigatoriamente ter o modificador `this`, indicando o tipo que está sendo estendido.

```csharp
namespace MeuProjeto.Extensoes;

public static class StringExtensions
{
    public static bool EhNuloOuVazio(this string? texto)
    {
        return string.IsNullOrEmpty(texto);
    }

    public static string Truncar(this string texto, int tamanhoMaximo, string sufixo = "...")
    {
        if (string.IsNullOrEmpty(texto) || texto.Length <= tamanhoMaximo)
            return texto;

        return string.Concat(texto.AsSpan(0, tamanhoMaximo), sufixo);
    }
}
```

---

## 2. Como Usar

Para utilizar, basta garantir que o namespace onde a classe estática reside esteja importado com `using`:

```csharp
using MeuProjeto.Extensoes;

string descricao = "Este é um artigo completo sobre engenharia de software com C# e .NET.";
string resumo = descricao.Truncar(20); // "Este é um artigo com..."

Console.WriteLine(resumo);
```

---

## 3. Comportamento Crucial: O `this` pode ser Nulo!

Diferente de métodos de instância normais (que lançam `NullReferenceException` imediatamente ao serem invocados em uma variável nula), um método de extensão é apenas uma chamada estática com syntactic sugar:

```csharp
string? texto = null;

// Isto NÃO lança NullReferenceException na chamada:
bool vazio = texto.EhNuloOuVazio(); // Retorna true com segurança!

// O compilador traduz internamente para:
// bool vazio = StringExtensions.EhNuloOuVazio(texto);
```

Portanto, em métodos de extensão que exigem que o objeto exista, sempre valide `ArgumentNullException.ThrowIfNull(objeto)`.

---

## 4. Regras de Precedência e Resolução do Compilador

Se houver um método de instância com a mesma assinatura que um método de extensão, **o método de instância sempre tem prioridade e o método de extensão é ignorado**:

```csharp
public class Carro
{
    public void Ligar() => Console.WriteLine("Carro ligou.");
}

public static class CarroExtensoes
{
    public static void Ligar(this Carro c) => Console.WriteLine("Extensão ligar.");
}

// Ao chamar:
var carro = new Carro();
carro.Ligar(); // Executa o método de instância: "Carro ligou."
```

## 5. Exercícios de Fixação

**Fácil — 1.** Crie um método de extensão `EhPar(this int numero)` que retorna se o inteiro é par.

**Médio — 2.** Crie um método de extensão `ToMoedaReal(this decimal valor)` que formata o número como moeda brasileira (`pt-BR`) garantindo padrão `R$ 0,00`.

**Desafiador — 3.** Crie um método de extensão `RemoverAcentos(this string texto)` que decompõe os caracteres Unicode (`NormalizationForm.FormD`) e remove marcas diacríticas (acentos e cedilhas) de forma eficiente.
