# 01.7 — Pattern Matching e Expressões Switch Modernas

> **Fase 01 — C# Básico: a linguagem em profundidade** · Aula 7
> Objetivo: dominar as técnicas modernas de pattern matching introduzidas no C# 8 até C# 12: type patterns, property patterns, positional patterns, relational/logical patterns e switch expressions.

---

## 1. O que é Pattern Matching?

Pattern matching é a capacidade da linguagem de inspecionar a forma, tipo, propriedades e valores de um dado de maneira declarativa, combinando teste e extração de variáveis em uma única operação limpa.

---

## 2. Padrões de Tipo e Declaração (`is Type var`)

```csharp
object dado = "Exemplo de texto";

// Testa o tipo e cria a variável local com cast garantido:
if (dado is string texto && texto.Length > 5)
{
    Console.WriteLine($"Texto longo: {texto.ToUpper()}");
}
```

---

## 3. Padrões Relacionais e Lógicos (`and`, `or`, `not`, `>`, `<`)

```csharp
static string ClassificarTemperatura(double temp) => temp switch
{
    < 0 => "Congelante",
    >= 0 and < 15 => "Frio",
    >= 15 and <= 25 => "Agradável",
    > 25 and <= 35 => "Quente",
    _ => "Extremo"
};
```

O operador `not` substitui negações complexas:

```csharp
if (cliente is not null)
{
    // ...
}
```

---

## 4. Padrões de Propriedade (Property Pattern)

Permite inspecionar diretamente as propriedades de um objeto sem navegar manualmente com múltiplos `&&`:

```csharp
public record Pedido(decimal ValorTotal, string Pais, bool ClienteVip);

static decimal CalcularDesconto(Pedido pedido) => pedido switch
{
    { ClienteVip: true, ValorTotal: > 500m } => 0.20m, // 20%
    { ClienteVip: true }                     => 0.10m, // 10%
    { Pais: "BR", ValorTotal: > 200m }       => 0.05m, // 5%
    _                                        => 0.00m
};
```

---

## 5. Padrões Posicionais e Tuplas (Positional Patterns)

Combinando com a desconstrução de classes ou records:

```csharp
static string IdentificarQuadrante((int X, int Y) ponto) => ponto switch
{
    (0, 0) => "Origem",
    ( > 0, > 0) => "Quadrante 1",
    ( < 0, > 0) => "Quadrante 2",
    ( < 0, < 0) => "Quadrante 3",
    ( > 0, < 0) => "Quadrante 4",
    _ => "Sobre um dos eixos"
};
```

## 6. Exercícios de Fixação

**Fácil — 1.** Escreva um método `EhNumeroValido(object entrada)` que retorna `true` se o objeto for um `int`, `long` ou `decimal` maior que zero utilizando pattern matching.

**Médio — 2.** Crie uma hierarquia de classes ou records representando formas geométricas (`Circulo(double Raio)`, `Retangulo(double Largura, double Altura)` e `Triangulo(double Base, double Altura)`). Escreva uma função `CalcularArea(object forma)` utilizando `switch expression` para retornar a área de cada forma.

**Desafiador — 3.** Escreva uma função `ValidarAcesso(string perfil, bool horarioComercial, bool emPlantao)` utilizando pattern matching posicional de tupla que determine se o usuário pode acessar o sistema crítico conforme regras estritas.
