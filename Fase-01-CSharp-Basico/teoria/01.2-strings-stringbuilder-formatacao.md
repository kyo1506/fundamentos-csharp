## 1. A Natureza da `System.String` no .NET

A classe `string` é um tipo por referência com características únicas:
- **Imutabilidade:** uma vez instanciada na Heap, o array interno de caracteres `char[]` de uma string jamais pode ser modificado.
- Qualquer método que parece alterar uma string (`Replace`, `ToUpper`, `Substring`, concatenação `+`) na verdade aloca uma **nova string** na memória.
- **Tabela de Internamento (String Interning):** literais idênticos no código-fonte compartilham o mesmo endereço na Heap para economizar memória.

```csharp
string s1 = "DotNet";
string s2 = "DotNet";

// Ambas apontam exatamente para a mesma referência devido ao interning de literais
Console.WriteLine(object.ReferenceEquals(s1, s2)); // True

// Ao "alterar", cria-se uma nova instância:
string s3 = s1.ToUpper();
Console.WriteLine(object.ReferenceEquals(s1, s3)); // False
```

## 2. A Armadilha da Concatenação em Loops

Concatenar strings repetidamente com o operador `+` gera complexidade de alocação quadrática $O(N^2)$:

```csharp
// ❌ PÉSSIMO: Gera centenas de strings intermediárias na Heap descartadas no segundo seguinte
string relatorio = "";
for (int i = 0; i < 1000; i++)
{
    relatorio += $"Item {i}, "; // 1000 alocações na Heap!
}
```

Cada iteração precisa copiar todo o texto acumulado até o momento para um novo array maior na Heap.

## 3. A Solução de Alta Performance: `StringBuilder`

O `StringBuilder` (namespace `System.Text`) gerencia um buffer mutável interno, expandindo a capacidade exponencialmente quando necessário:

```csharp
using System.Text;

// ✅ EXCELENTE: especifique a capacidade inicial estimada para evitar redimensionamentos
var sb = new StringBuilder(capacity: 2048);
for (int i = 0; i < 1000; i++)
{
    sb.Append("Item ").Append(i).Append(", ");
}
string relatorioFinal = sb.ToString();
```

### Boas Práticas com StringBuilder
1. Sempre que souber o tamanho aproximado do resultado, forneça o parâmetro `capacity` no construtor.
2. Em loops com interpolação, prefira `.Append(variavel)` em vez de `.Append($"...{variavel}")` para evitar alocação da string interpolada antes de entrar no buffer.
3. Chame `.Clear()` para reutilizar instâncias em cenários de alta frequência (ou use `StringBuilderPool`).

## 4. Comparação de Strings: Regras Críticas

Nunca compare strings contendo identificadores, códigos de barras ou dados técnicos sem explicitar a regra de comparação:

```csharp
string codigoA = "PROD_123";
string codigoB = "prod_123";

// ❌ Frágil: depende da cultura configurada na máquina do usuário/servidor
bool igual = codigoA.ToLower() == codigoB.ToLower(); // Aloca duas novas strings!

// ✅ Recomendado: sem alocações e com intenção clara
bool igualOrdinal = string.Equals(codigoA, codigoB, StringComparison.OrdinalIgnoreCase);
```

### Tipos de `StringComparison`
- `Ordinal`: compara byte a byte (código ASCII/Unicode numérico). **Mais rápida e recomendada para dados técnicos, chaves, URLs e JSON**.
- `OrdinalIgnoreCase`: comparação rápida insensível a maiúsculas/minúsculas sem regras linguísticas.
- `CurrentCulture` / `CurrentCultureIgnoreCase`: segue a cultura do sistema operacional da thread atual (útil para ordenação alfabética em UI para o usuário).
- `InvariantCulture`: segue regras universais inglesas, consistente em qualquer máquina.

## 5. Formatação Composta e Especificadores de Formato

C# suporta formatação rica integrada tanto no `string.Format` quanto na interpolação `$""`:

```csharp
decimal valor = 1599.90m;
DateTime data = new(2026, 9, 21, 14, 30, 0);

// Moeda e precisão
Console.WriteLine($"{valor:C}");       // Ex.: R$ 1.599,90 (depende da cultura)
Console.WriteLine($"{valor:N2}");      // 1.599,90
Console.WriteLine($"{valor:F2}");      // 1599.90 (ponto fixo)

// Alinhamento em tabelas: {valor, largura}
Console.WriteLine($"| {"ID",-5} | {"PRODUTO",-15} | {"VALOR",10} |");
Console.WriteLine($"| {1,-5} | {"Teclado",-15} | {valor,10:N2} |");
```

### Cultura Estrita (`CultureInfo`)
Para garantir integridade em logs, APIs ou arquivos fiscais:

```csharp
using System.Globalization;

var ptBr = new CultureInfo("pt-BR");
var enUs = CultureInfo.InvariantCulture;

Console.WriteLine(valor.ToString("C", ptBr)); // "R$ 1.599,90"
Console.WriteLine(valor.ToString("F2", enUs)); // "1599.90"
```
