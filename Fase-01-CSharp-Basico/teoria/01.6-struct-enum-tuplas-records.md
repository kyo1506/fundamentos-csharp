# 01.6 — Estruturas, Enumerações, Tuplas e Records

> **Fase 01 — C# Básico: a linguagem em profundidade** · Aula 6
> Objetivo: dominar as ferramentas modernas de modelagem de dados leves do C#: readonly structs, enums com flags, tuplas nomeadas de valor e records com mutação não-destrutiva.

---

## 1. `struct` e `readonly struct`

Use `struct` para pequenos objetos de dados (geralmente < 16 a 24 bytes) com tempo de vida curto e sem herança:

```csharp
// ✅ readonly struct: o compilador impede mutações e garante passagem segura
public readonly struct Dinheiro
{
    public decimal Valor { get; }
    public string Moeda { get; }

    public Dinheiro(decimal valor, string moeda = "BRL")
    {
        if (valor < 0) throw new ArgumentOutOfRangeException(nameof(valor), "Valor não pode ser negativo.");
        Valor = valor;
        Moeda = moeda ?? throw new ArgumentNullException(nameof(moeda));
    }

    public override string ToString() => $"{Moeda} {Valor:N2}";
}
```

## 2. `enum` e `[Flags]`

Enums são tipos por valor inteiros nomeados:

```csharp
public enum StatusPedido
{
    Pendente = 1,
    Pago = 2,
    Enviado = 3,
    Entregue = 4,
    Cancelado = 5
}

// Flags permitem operações bit a bit (bitwise OR / AND) para múltiplas permissões:
[Flags]
public enum Permissoes
{
    Nenhuma   = 0,
    Leitura   = 1 << 0, // 1
    Escrita   = 1 << 1, // 2
    Exclusao  = 1 << 2, // 4
    Admin     = Leitura | Escrita | Exclusao // 7
}

var perfil = Permissoes.Leitura | Permissoes.Escrita;
bool podeEscrever = perfil.HasFlag(Permissoes.Escrita); // True
```

## 3. Tuplas de Valor (`ValueTuple`)

Introduzidas no C# 7, são alocadas na Stack e substituem a necessidade de criar classes temporárias para retornos múltiplos:

```csharp
static (bool Sucesso, int Quociente, int Resto) DividirComResto(int dividendo, int divisor)
{
    if (divisor == 0) return (false, 0, 0);
    return (true, dividendo / divisor, dividendo % divisor);
}

// Desconstrução de tuplas:
var (ok, q, r) = DividirComResto(10, 3);
Console.WriteLine($"Sucesso: {ok}, Quociente: {q}, Resto: {r}");
```

## 4. `record` (Classes e Structs com Semântica de Valor)

Introduzidos no C# 9 (e `record struct` no C# 10), os `records` são o padrão moderno para DTOs e Value Objects:
- **Igualdade baseada em valores**, e não em referência de ponteiro!
- Implementação automática de `ToString()` formatado, `GetHashCode()` e desconstrução.
- Suporte a expressões `with` para **mutação não-destrutiva**.

```csharp
// Record class posicional e imutável
public record Endereco(string Rua, string Cidade, string Cep);

var end1 = new Endereco("Av. Paulista, 1000", "São Paulo", "01310-100");
var end2 = new Endereco("Av. Paulista, 1000", "São Paulo", "01310-100");

Console.WriteLine(end1 == end2); // TRUE! Compara as propriedades, não ponteiro

// Mutação não-destrutiva com 'with':
var endMudou = end1 with { Rua = "Av. Paulista, 2000" };
Console.WriteLine(endMudou.Rua); // "Av. Paulista, 2000"
Console.WriteLine(end1.Rua);      // "Av. Paulista, 1000" intacto
```
