# 00.4 — Entrada, saída e formatação

> **Fase 00** · Aula 4
> Objetivo: ler do usuário, escrever na tela e formatar texto/números corretamente.

## 1. Saída: `Console.WriteLine` e `Console.Write`

```csharp
Console.WriteLine("Oi");   // imprime e pula linha
Console.Write("Oi");       // imprime SEM pular linha
```

## 2. Interpolação de strings `$"..."`

A forma moderna e preferida de montar texto com valores:

```csharp
string nome = "Beatriz";
int idade = 25;
Console.WriteLine($"Olá, {nome}! Você tem {idade} anos.");
```

> ✅ Sempre prefira **interpolação** (`$"..."`) a concatenar com `+`. É mais legível e segura.
> ```csharp
> Console.WriteLine("Olá, " + nome + "! Você tem " + idade + " anos."); // ❌ legível, mas pior
> ```

## 3. Entrada: `Console.ReadLine()`

```csharp
Console.Write("Digite seu nome: ");
string? nome = Console.ReadLine();   // retorna string? (pode ser nulo)
Console.WriteLine($"Prazer, {nome}!");
```

### Converter texto digitado em número
Tudo que entra pelo teclado é `string`. Para usar como número, **converta**:

```csharp
Console.Write("Digite a idade: ");
string entrada = Console.ReadLine() ?? "";
bool converteu = int.TryParse(entrada, out int idade);

if (converteu)
    Console.WriteLine($"Idade: {idade}");
else
    Console.WriteLine("Valor inválido para idade.");
```

> Prefira **`int.TryParse`** (retorna `bool` e não lança erro) a `int.Parse`
> (que **lança exceção** se falhar). O mesmo vale para `double.TryParse`, `decimal.TryParse`.

## 4. Formatação de números e datas

### Formatação inline (na interpolação)
```csharp
decimal preco = 1234.5m;
Console.WriteLine($"{preco:C}");   // moeda: R$ 1.234,50 (segue a cultura)
Console.WriteLine($"{preco:N2}");  // número com 2 casas: 1.234,50
Console.WriteLine($"{preco:0.00}");// 1234,50
Console.WriteLine($"{0.5:P0}");    // percentual: 50%
```

### Cultura (importante no Brasil)
A formatação de moeda/vírgula depende da **cultura** do sistema. Para forçar padrão brasileiro:

```csharp
using System.Globalization;
Console.WriteLine(preco.ToString("C", new CultureInfo("pt-BR"))); // R$ 1.234,50
```

> ⚠️ Em apps que usam ponto ou vírgula decimal, defina a cultura no início do processo:
> `CultureInfo.DefaultThreadCurrentCulture = new CultureInfo("pt-BR");`

### Alinhamento / casas
```csharp
Console.WriteLine($"|{"Item",-10}|{"Qtd",5}|");   // -10 alinha à esquerda, 5 à direita
```

## 5. Programa completo de exemplo

```csharp
Console.Write("Produto: ");
string produto = Console.ReadLine() ?? "?";
Console.Write("Preço: ");
bool ok = decimal.TryParse(Console.ReadLine(), out decimal preco);

if (!ok)
{
    Console.WriteLine("Preço inválido.");
    return;          // encerra o programa aqui (veremos fluxo em breve)
}

Console.WriteLine($"Você comprou {produto} por {preco:C}.");
```

## 6. Anti-exemplos

```csharp
// ❌ int.Parse sem garantia de que é número (quebra se o usuário digitar letra)
int idade = int.Parse(Console.ReadLine()!);

// ✅ TryParse tratando erro
if (int.TryParse(Console.ReadLine(), out int idade))
    Console.WriteLine($"Idade: {idade}");
else
    Console.WriteLine("Número inválido.");
```
