# 00.8 — Vetores (arrays) e `string`

> **Fase 00** · Aula 8
> Objetivo: guardar sequências de valores e trabalhar com texto.

## 1. O que é um array (vetor)

Um `array` é uma sequência **fixa** de elementos **do mesmo tipo**, indexada a partir de **0**.

```csharp
int[] numeros = new int[5];          // 5 inteiros (todos 0 por padrão)
string[] nomes = { "Ana", "Bia", "Caio" };   // inicialização direta
int[] pares = new int[] { 2, 4, 6, 8 };
```

### Acessar por índice
```csharp
string[] nomes = { "Ana", "Bia", "Caio" };
Console.WriteLine(nomes[0]);   // Ana
Console.WriteLine(nomes[2]);   // Caio
nomes[1] = "Beatriz";          // muda o elemento 1
Console.WriteLine(nomes.Length); // 3
```

> ⚠️ O último índice é `Length - 1`. Acessar `nomes[3]` lança `IndexOutOfRangeException`.

### Percorrer
```csharp
for (int i = 0; i < nomes.Length; i++)   // com índice (para saber a posição)
    Console.WriteLine($"{i}: {nomes[i]}");

foreach (var nome in nomes)              // sem índice (só para ler)
    Console.WriteLine(nome);
```

### Arrays 2D (matrizes)
```csharp
int[,] matriz = { { 1, 2, 3 }, { 4, 5, 6 } };
Console.WriteLine(matriz[1, 2]); // 6 (linha 1, coluna 2)
Console.WriteLine(matriz.GetLength(0)); // 2 linhas
```

## 2. `string` — o tipo texto

Uma `string` é, por baixo, uma **sequência imutável de caracteres** (`char`). Imutável =
uma vez criada, não muda; operações que "modificam" criam uma **nova** string.

```csharp
string s = "Olá, mundo!";
Console.WriteLine(s.Length);       // 11
Console.WriteLine(s.ToUpper());    // OLÁ, MUNDO!  (nova string)
Console.WriteLine(s.Contains("mundo")); // True
Console.WriteLine(s.StartsWith("Olá")); // True
Console.WriteLine(s.Replace("mundo", "C#"));
```

### Acessar caracteres
```csharp
string nome = "Beatriz";
Console.WriteLine(nome[0]);   // 'B'  (cuidado: string é indexada por char, não substring)
Console.WriteLine(nome[^1]);  // 'z'  (último, com operador de índice do fim)
```

### Substrings e partes
```csharp
string frase = "Aprender C# é ótimo";
Console.WriteLine(frase.Substring(9));    // "C# é ótimo"
Console.WriteLine(frase.Substring(9, 2)); // "C#"
Console.WriteLine(frase.Split(' '));      // ["Aprender","C#","é","ótimo"]
```

### Verificar vazio / nulo
```csharp
string? s = null;
bool a = string.IsNullOrEmpty(s);    // true (null OU "")
bool b = string.IsNullOrWhiteSpace(s); // true (também conta espaços)
```
> Prefira `string.IsNullOrWhiteSpace` para validar entradas digitadas.

## 3. Comparação de strings

```csharp
string a = "casa";
string b = "CASA";
bool igual1 = a == b;                       // false (diferencia maiúsculas)
bool igual2 = a.Equals(b, StringComparison.OrdinalIgnoreCase); // true
bool comeca = a.StartsWith("ca");           // true
```

## 4. `StringBuilder` — quando montar muito texto

Cada `+` de string cria uma nova string. Para **muitas** concatenações em laço, use `StringBuilder`
(a Fase 01 detalha). Regra prática: laço curto → `+`/interpolação; laço grande → `StringBuilder`.

## 5. Anti-exemplos

```csharp
// ❌ confundir Length de array com último índice
for (int i = 0; i <= arr.Length; i++)   // estoura

// ❌ comparar string com == ignorando acento/caixa quando não quer
// ✅ usar OrdinalIgnoreCase quando quiser ignorar caixa

// ❌ tentar mudar string no lugar (não dá — é imutável)
s[0] = 'x';  // não compila
```

## 6. Exercícios

**Fácil — 1.** Dado `int[] v = { 4, 7, 1, 9, 3 }`, imprima: soma, maior, menor e média (use laço).

**Médio — 2.** Leia uma frase e imprima: número de palavras (use `Split`), e a frase com todas
as palavras começando com maiúscula.

**Desafiador — 3.** Escreva uma função que recebe uma `string` e retorna `true` se ela é um
**palíndromo** (ex.: "arara", "socorram me subi no onibus em marrocos") ignorando espaços,
pontuação e maiúsculas. Não use o método pronto de inverter — use índices `i`/`j` comparando
das pontas para dentro.
