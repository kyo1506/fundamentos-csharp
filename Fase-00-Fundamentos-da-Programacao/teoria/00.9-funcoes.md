# 00.9 — Funções (métodos): reutilizar e organizar código

> **Fase 00** · Aula 9
> Objetivo: escrever blocos reutilizáveis que recebem entradas e devolvem um resultado.

## 1. Por que usar funções?
1. **Reutilização** — escreva uma vez, chame muitas vezes.
2. **Legibilidade** — código curto e nomeado que "conta uma história".
3. **Testabilidade** — função pura (mesma entrada → mesma saída) é fácil de testar.
4. **Manutenção** — corrige num lugar só.

## 2. Sintaxe

```csharp
// <tipo-de-retorno> Nome(<parâmetros>) { corpo }
static int Soma(int a, int b)
{
    return a + b;
}

// Uso:
int resultado = Soma(3, 4);   // 7
```

- **Retorno**: o tipo após `static`. Se não devolve nada, use `void`.
- **`return`** devolve um valor **e encerra a função**.
- Cada função deve fazer **uma coisa só**.

```csharp
static void ImprimirBoasVindas(string nome)
{
    Console.WriteLine($"Olá, {nome}!");
}

static bool EhAdulto(int idade) => idade >= 18;   // arrow para funções curtas
```

## 3. Parâmetros: opcionais e nomeados

```csharp
static void Saudar(string nome, string saudacao = "Olá")  // 'saudacao' opcional
{
    Console.WriteLine($"{saudacao}, {nome}!");
}

Saudar("Ana");                 // usa padrão "Olá"
Saudar("Ana", "Bom dia");      // sobrescreve
Saudar(saudacao: "Oi", nome: "Bia");  // argumentos nomeados (ordem livre)
```

## 4. Parâmetro `params` e `out`

```csharp
static int SomarTodos(params int[] numeros)  // aceita vários argumentos
{
    int soma = 0;
    foreach (var n in numeros) soma += n;
    return soma;
}
SomarTodos(1, 2, 3, 4);   // 10

// 'out' permite "devolver" mais de um valor
static bool EhParOuImpar(int n, out string rotulo)
{
    rotulo = n % 2 == 0 ? "par" : "ímpar";
    return n % 2 == 0;
}
```

> ⚠️ Prefira retornar uma **tupla** (`(bool Sucesso, string Msg)`) ou um tipo próprio a
> usar muitos `out`. `out` fica reservado para casos como `TryParse`.

## 5. Escopo e variáveis locais

```csharp
static int Calcular(double preco)
{
    double imposto = preco * 0.1;   // 'imposto' existe só dentro da função
    return (int)(preco + imposto);
}
// aqui fora, 'imposto' NÃO existe
```

Regra: variáveis declaradas dentro de um bloco `{ }` só são visíveis dentro dele.

## 6. "Função pura" — conceito que vale ouro

Uma função **pura**:
- dado o mesmo argumento, sempre retorna o mesmo valor;
- não lê teclado, não imprime, não muda estado externo.

```csharp
// Puras (fáceis de testar)
static double Media(double a, double b) => (a + b) / 2;
static bool EhPar(int n) => n % 2 == 0;

// Com efeito colateral (mais difícil de testar isolado)
static void MostrarMediaNoConsole(double a, double b) => Console.WriteLine(Media(a, b));
```

> Boa arquitetura: mantenha a **regra** em função pura e deixe o **Console/entrada**
> no chamador. É isso que permite testes automáticos (xUnit) — como fizemos no `Logica.cs`.

## 7. Programas se tornam "orquestração de funções"

```csharp
static void Main()
{
    string nome = LerNome();
    double nota = LerNota();
    string situacao = ClassificarMedia(nota);
    ImprimirResultado(nome, nota, situacao);
}
```
Cada passo é uma função pequena e clara.

## 8. Anti-exemplos

```csharp
// ❌ função fazendo muitas coisas
static void ProcessarConta() { /* lê, valida, calcula, imprime, salva... */ }

// ✅ separar responsabilidades
static decimal CalcularTotal(...);
static bool ValidarConta(...);
static void Salvar(...);
```

## 9. Exercícios

**Fácil — 1.** Crie `static bool EhPar(int)` e `static bool EhPositivo(int)` e use em um pequeno
menu para classificar números digitados.

**Médio — 2.** Crie `static double CalcularImc(double peso, double altura)` e
`static string FaixaImc(double imc)` (funções puras) e um `Main` que lê os dados e exibe.

**Desafiador — 3.** Crie uma função pura `static int ContarPalavras(string frase)` que
conta palavras separando por espaços. Depois crie um teste mental (ou no projeto integrador)
verificando casos: vazio, espaços múltiplos, pontuação.
