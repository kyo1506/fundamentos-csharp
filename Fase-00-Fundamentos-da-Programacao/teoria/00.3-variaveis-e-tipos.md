# 00.3 — Estrutura de um programa C# e variáveis

> **Fase 00** · Aula 3
> Objetivo: ler um programa C# e guardar dados em memória com variáveis e tipos básicos.

## 1. Anatomia de um programa

Cada instrução termina com `;`. O C# executa **de cima para baixo**, instrução por instrução.

```csharp
// Comentário de linha
int idade = 25;                 // declara uma variável 'idade' e guarda 25
Console.WriteLine(idade);       // imprime 25
idade = 26;                     // sobrescreve o valor
Console.WriteLine(idade);       // imprime 26
```

### Comentários
```csharp
// comentário de linha
/* comentário de
   várias linhas */
/// <summary>Comentário de documentação (aparece em tooltips)</summary>
```

## 2. Variáveis: caixinhas com nome e tipo

Uma variável é um **espaço nomeado na memória** que guarda um valor de **um tipo fixo**.

```csharp
<tipo> <nome> = <valor>;
int    idade  = 25;
```

O **tipo** diz *o que* cabe (número inteiro? texto? verdadeiro/falso?) e o **tamanho** em memória.

### Tipos básicos mais usados
| Tipo | Guarda | Exemplo |
|------|--------|---------|
| `int` | inteiro (32 bits) | `-2147483648..2147483647` |
| `long` | inteiro grande (64 bits) | `9_000_000_000L` |
| `double` | número com casas (64 bits) | `3.14159` |
| `decimal` | dinheiro/preciso (128 bits) | `15.90m` |
| `bool` | verdadeiro/falso | `true` |
| `char` | um caractere | `'A'` |
| `string` | texto (sequência de `char`) | `"Olá"` |

```csharp
int ano = 2026;
long populacao = 8_000_000_000L;   // underline melhora a leitura
double pi = 3.14159;
decimal preco = 19.99m;            // sufixo 'm' = decimal
bool aprovado = true;
char letra = 'A';
string nome = "Beatriz";
```

> ⚠️ `decimal` tem sufixo `m`; `long` tem `L`. **Sempre** use `decimal` (não `double`)
> para dinheiro/valores que precisam de exatidão — `double` tem erro de arredondamento.

## 3. Inferência de tipo com `var`

Você pode deixar o compilador descobrir o tipo:

```csharp
var idade = 25;        // o compilador entende: é int
var nome = "Ana";      // é string
```

`var` **não** é "sem tipo" nem dinâmico: o tipo é fixado na hora. Só funciona quando o
compilador consegue inferir na mesma linha (com inicialização).

**Bom uso:** nomes longos de tipo. **Mau uso:** quando esconde a intenção.
```csharp
var d = 3.14;                       // ok, mas...
double d = 3.14;                    // mais claro aqui
Dictionary<string, List<int>> mapa = new();   // 'var' ajuda muito aqui
var mapa = new Dictionary<string, List<int>>();
```

## 4. Constantes

Uma constante **não muda** após definida:

```csharp
const double PI = 3.14159;
const int DIAS_SEMANA = 7;
// PI = 3; // ❌ ERRO: constante não pode mudar
```

Use constantes para valores que têm significado e não devem variar (evita "números mágicos").

## 5. Nomenclatura (convenções C#)

| Contexto | Convenção | Exemplo |
|----------|-----------|---------|
| variáveis locais / parâmetros | `camelCase` | `totalCompra` |
| campos privados | `_camelCase` | `_saldo` |
| constantes | `PascalCase` ou `UPPER_SNAKE` | `LimiteMaximo` |
| classes / métodos / propriedades públicas | `PascalCase` | `Cliente`, `CalcularTotal` |

## 6. Anti-exemplos

```csharp
// ❌ nome sem sentido / magia numérica
int x = 60;                       // o que é 60?

// ✅ nome intencional
const int MINUTOS_EM_UMA_HORA = 60;
int minutosRestantes = 60;

// ❌ tipo errado para dinheiro
double salario = 2500.10;

// ✅ decimal para dinheiro
decimal salario = 2500.10m;
```
