# 00.6 — Decisões: `if`, `else`, `switch`

> **Fase 00** · Aula 6
> Objetivo: fazer o programa tomar rumos diferentes conforme condições.

## 1. `if / else if / else`

```csharp
int nota = 78;

if (nota >= 90)
    Console.WriteLine("Excelente");
else if (nota >= 70)
    Console.WriteLine("Bom");
else if (nota >= 50)
    Console.WriteLine("Regular");
else
    Console.WriteLine("Reprovado");
```

### Regras
- A condição entre `( )` precisa ser um `bool`.
- **`else if`** permite encadear. A ordem **importa** (a primeira que for verdadeira vence).
- `else` é opcional.
- **Bloco com chaves** `{ }` é obrigatório quando há mais de uma instrução; use sempre para evitar bugs.

```csharp
// PEGADINHA clássica: sem chaves, apenas a PRIMEIRA linha pertence ao if
if (saldo < 0)
    Console.WriteLine("Negativo");
    Console.WriteLine("Sempre imprime");   // NÃO faz parte do if!
```

## 2. Expressão condicional (ternário) `? :`

Para atribuir um de dois valores de forma concisa:

```csharp
string status = nota >= 60 ? "Aprovado" : "Reprovado";
// equivalente a:
string status;
if (nota >= 60) status = "Aprovado"; else status = "Reprovado";
```

Use ternário **apenas** para escolhas simples de 2 vias; para lógica maior, prefira `if`.

## 3. `switch` (forma clássica)

```csharp
string dia = "seg";

switch (dia)
{
    case "sab":
    case "dom":
        Console.WriteLine("Fim de semana");
        break;
    case "seg":
        Console.WriteLine("Começa a semana");
        break;
    default:
        Console.WriteLine("Dia de semana");
        break;
}
```

> Não esqueça o `break` (ou `return`). Em C#, cada `case` precisa "terminar".

## 4. `switch` como expressão (moderna) — preferida

Desde o C# 8 é possível usar `switch` **retornando valor**:

```csharp
string rotulo = nota switch
{
    >= 90 => "Excelente",
    >= 70 => "Bom",
    >= 50 => "Regular",
    _     => "Reprovado"     // '_' = caso padrão (default)
};
```

Vantagens: mais curto, sem `break`, sem chance de "cair" de um caso para outro.

### Outra forma com `when`
```csharp
string faixa = idade switch
{
    < 13 => "Criança",
    < 18 => "Adolescente",
    < 60 => "Adulto",
    _    => "Idoso"
};
```

## 5. Comparar com pattern matching (avançando)

Na Fase 01 veremos *pattern matching* a fundo. Já aqui, perceba que em vez de comparar só
valores, o `switch` de expressão entende intervalos (`>= 90`, `< 18`).

## 6. Decisão + lógica combinadas

```csharp
static string AvaliarAcesso(int idade, bool temIngresso, bool ehVip) =>
    (idade >= 18 && temIngresso) || ehVip
        ? "Pode entrar"
        : "Não pode entrar";
```

## 7. Exercícios

**Fácil — 1.** Leia uma nota (0–10) e imprima: A (>=9), B (>=7), C (>=5), D (>=3), E (senão).

**Médio — 2.** Leia 3 números e imprima o **maior** e o **menor** usando apenas `if` (sem `Math.Max`).

**Desafiador — 3.** Reimplemente um "classificador de IMC": leia peso e altura, calcule
`imc = peso / (altura*altura)` e imprima a faixa usando **switch de expressão**:
`< 18.5` Baixo · `< 25` Normal · `< 30` Sobrepeso · `_` Obesidade. Trate altura `<= 0`.
