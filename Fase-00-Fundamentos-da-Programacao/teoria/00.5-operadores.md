# 00.5 — Operadores

> **Fase 00** · Aula 5
> Objetivo: dominar os operadores do C# (aritmética, comparação, lógica) e a precedência.

## 1. Operadores aritméticos

| Operador | Operação | Exemplo | Resultado |
|----------|----------|---------|-----------|
| `+` | soma | `7 + 3` | `10` |
| `-` | subtração | `7 - 3` | `4` |
| `*` | multiplicação | `7 * 3` | `21` |
| `/` | divisão | `7 / 3` | `2` *(ver nota)* |
| `%` | resto (módulo) | `7 % 3` | `1` |
| `++` | incrementa | `n++` | n+1 |
| `--` | decrementa | `n--` | n-1 |

### ⚠️ Divisão de inteiros vs decimais
```csharp
Console.WriteLine(7 / 2);      // 3   (divisão inteira — descarta a casa!)
Console.WriteLine(7.0 / 2);    // 3.5 (pelo menos um é decimal/double)
Console.WriteLine(7m / 2m);    // 3.5 (decimal)
```
Se **ambos** os operandos são `int`, a divisão é **inteira** (trunca). Para obter casas,
use `double`/`decimal` ou converta: `(double)a / b`.

### `%` (resto) — muito útil
```csharp
Console.WriteLine(10 % 3);   // 1
Console.WriteLine(10 % 2);   // 0  → par
Console.WriteLine(9 % 2);    // 1  → ímpar
```

## 2. Operadores de atribuição

```csharp
int x = 10;
x += 5;    // x = 15   (equivale a x = x + 5)
x -= 3;    // x = 12
x *= 2;    // x = 24
x /= 4;    // x = 6
x %= 5;    // x = 1
```

## 3. Operadores de comparação (retornam `bool`)

| Operador | Significado | Exemplo |
|----------|-------------|---------|
| `==` | igual | `a == b` |
| `!=` | diferente | `a != b` |
| `>` | maior | `a > b` |
| `<` | menor | `a < b` |
| `>=` | maior ou igual | `a >= b` |
| `<=` | menor ou igual | `a <= b` |

> ⚠️ Compare **valor** com `==`/`!=`. Em C#, para números/bool funcionam; para **strings**
> `==` compara o conteúdo (ok), mas para objetos comparados por referência o comportamento
> muda — veremos isso em profundidade na Fase 01/02. Aqui: para números, use normalmente.

## 4. Operadores lógicos

| Operador | Significado | Exemplo |
|----------|-------------|---------|
| `&&` | E (AND) | `a > 0 && b > 0` |
| `\|\|` | OU (OR) | `a > 0 \|\| b > 0` |
| `!` | NÃO (NOT) | `!ativo` |

```csharp
int idade = 25;
bool temIngresso = true;

bool podeEntrar = idade >= 18 && temIngresso;   // true
bool ehAdultoOuIdoso = idade >= 18 || idade >= 65;
bool naoMenor = !(idade < 18);
```

### Curto-circuito
`&&` e `||` avaliam **só o necessário**. Em `a && b`, se `a` é `false`, `b` nem é avaliado.
Isso permite escrever com segurança:
```csharp
string? nome = null;
bool temNomeLongo = nome != null && nome.Length > 3;   // não quebra se nome for nulo
```

## 5. Precedência e parênteses

Assim como na matemática, há ordem de avaliação. **Use parênteses para clareza** sempre que
houver mistura de operadores.

```csharp
// Sem parênteses, a precedência pode surpreender:
int r1 = 2 + 3 * 4;      // 14 (multiplicação antes)
int r2 = (2 + 3) * 4;    // 20

bool ok = idade >= 18 && temIngresso || ehVip;   // ambíguo p/ leitura humana
bool claro = (idade >= 18 && temIngresso) || ehVip;  // ✅
```

Precedência resumida (do maior para o menor): parênteses → `!` → `* / %` → `+ -` →
comparações (`< <= > >=`) → igualdade (`== !=`) → `&&` → `||` → atribuição.

## 6. Anti-exemplos / pegadinhas

```csharp
// ❌ usar = em vez de == na comparação
if (idade = 18) ...          // não compila (ou pior, em algumas linguagens atribui!)

// ❌ divisão inteira inesperada
double media = (7 + 8 + 9) / 3;   // 8.0? Não! (7+8+9)/3 = 24/3 = 8 int → 8.0 por acaso
double media = (7 + 8 + 9) / 3.0; // melhor: 3.0

// ❌ esquecer de somar casas decimais corretas (usar int onde deveria haver decimal)
```
