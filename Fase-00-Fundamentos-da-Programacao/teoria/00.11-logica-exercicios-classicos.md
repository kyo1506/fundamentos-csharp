# 00.11 — Lógica de programação: exercícios clássicos

> **Fase 00** · Aula 11 · **Projeto integrador da fase**
> Objetivo: consolidar tudo da Fase 00 resolvendo problemas clássicos com funções puras + testes.

Nesta aula você monta, junto com o `LogicaEmAcao`, um **menu de lógica**. Cada problema vira
uma **função pura** (testável) no `Logica.cs`. NÃO coloque lógica de "mostrar na tela" dentro
das funções — deixe o `Program` (ou o menu) responsável pela entrada/saída.

## Regras de ouro para esta aula
1. Antes de codar um problema, faça um **teste de mesa** para 2–3 entradas.
2. Implemente a **função pura**.
3. Adicione **testes** no projeto `aplicacao.Tests`.
4. Depois conecte ao menu do `Program`.

## Exercícios (fácil → desafiador)

### 1. FizzBuzz (fácil)
Função `static string FizzBuzz(int n)`:
- múltiplo de 3 e 5 → `"FizzBuzz"`; só de 3 → `"Fizz"`; só de 5 → `"Buzz"`; senão o número.
Teste: `15→FizzBuzz`, `9→Fizz`, `10→Buzz`, `7→"7"`.

### 2. Soma de dígitos (fácil)
`static int SomarDigitos(int n)` soma os dígitos de um inteiro positivo.
`123 → 6`; `9999 → 36`. (Dica: use `% 10` para pegar o último dígito e `/ 10` para descartá-lo.)

### 3. Sequência de Fibonacci (médio)
`static long Fibonacci(int n)` devolve o n-ésimo termo (Fibonacci(0)=0, Fibonacci(1)=1).
Dica: itere com duas variáveis anteriores.

### 4. Maior e menor (médio)
`static (int Maior, int Menor) MaiorMenor(int[] v)` retorna ambos numa tupla.

### 5. Jogo "adivinhe o número" (médio, interativo)
Não é função pura (usa `Random`/entrada). No `Program`, sorteie 1–100 e dê dicas
"maior"/"menor" até acertar, contando tentativas.

### 6. Primos até N (desafiador)
`static int[] PrimosAte(int n)` retorna todos os primos ≤ n. Reaproveite `EhPrimo`.

### 7. Contar vogais (desafiador)
`static int ContarVogais(string texto)` conta `a,e,i,o,u` (maiúsculas/minúsculas, ignorar acentos
ou tratá-los — decida e documente).

### 8. Ordenar sem `Sort` (desafiador)
`static int[] OrdenarCrescente(int[] v)` — implemente **bolha** (bubble sort) você mesmo,
explicando por comentário o que cada iteração faz.

## Modelo de função + teste

```csharp
// Logica.cs
public static string FizzBuzz(int n) => (n % 3, n % 5) switch
{
    (0, 0) => "FizzBuzz",
    (0, _) => "Fizz",
    (_, 0) => "Buzz",
    _      => n.ToString()
};
```

```csharp
// LogicaTests.cs
[Theory]
[InlineData(15, "FizzBuzz")]
[InlineData(9, "Fizz")]
[InlineData(10, "Buzz")]
[InlineData(7, "7")]
public void FizzBuzz_RetornaEsperado(int n, string esperado)
    => Assert.Equal(esperado, Logica.FizzBuzz(n));
```
