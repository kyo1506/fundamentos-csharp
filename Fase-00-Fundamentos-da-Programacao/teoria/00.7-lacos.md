# 00.7 — Laços de repetição: `for`, `while`, `do-while`, `foreach`

> **Fase 00** · Aula 7
> Objetivo: repetir blocos de código com controle — a base de quase toda lógica.

## 1. `while` — repete enquanto a condição for verdadeira

```csharp
int contador = 1;
while (contador <= 5)
{
    Console.WriteLine(contador);
    contador++;
}
```
- A condição é testada **antes** de cada volta. Se começar falsa, o bloco **não roda**.
- Você é responsável por fazer a condição um dia virar falsa (senão = **loop infinito**).

## 2. `do-while` — roda pelo menos uma vez

```csharp
string? entrada;
do
{
    Console.Write("Digite 'sair' para encerrar: ");
    entrada = Console.ReadLine();
} while (entrada != "sair");
```
A condição é testada **depois** da primeira execução. Ideal para menus e validação de entrada.

## 3. `for` — contagem com controle

```csharp
for (inicialização; condição; incremento)
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);   // 0 1 2 3 4
}
```
É o laço para quando você sabe **quantas vezes** repetir, especialmente com índice.

```csharp
// de trás para frente
for (int i = 10; i >= 0; i -= 2)
    Console.WriteLine(i);   // 10 8 6 4 2 0
```

## 4. `foreach` — percorrer uma coleção/sequência

```csharp
string[] nomes = { "Ana", "Bia", "Caio" };
foreach (var nome in nomes)
    Console.WriteLine(nome);
```
- **Não** precisa de índice; percorre todos os elementos.
- É a forma mais segura/legível para percorrer listas. (Não dá para modificar a coleção durante o `foreach`.)

## 5. `break`, `continue` e `return`

```csharp
for (int i = 0; i < 100; i++)
{
    if (i == 3) continue;      // pula esta volta (não imprime 3)
    if (i == 6) break;         // encerra o laço de vez
    Console.WriteLine(i);      // 0 1 2 4 5
}
```
- `continue` → vai para a próxima volta.
- `break` → sai do laço.
- `return` (dentro de função) → sai da função inteira (encerra também o laço).

## 6. Loop infinito e como escapar

```csharp
while (true)          // comum em menus/processos que ficam ouvindo
{
    string? op = Console.ReadLine();
    if (op == "sair") break;
}
```
Use `while (true)` **com** uma saída (`break`/`return`). Evite em lógica de cálculo puro.

## 7. Quando usar qual?

| Situação | Laço |
|----------|------|
| Sei quantas vezes / preciso de índice | `for` |
| Não sei quantas, condição no início | `while` |
| Não sei quantas, mas roda ao menos 1x (menu) | `do-while` |
| Percorrer todos os itens de uma coleção | `foreach` |

## 8. Exemplos e pegadinhas

```csharp
// Somar de 1 a 100
int soma = 0;
for (int i = 1; i <= 100; i++) soma += i;

// Pegadinha: esquecer o incremento
// while (x < 10) { }  // sem x++ → loop infinito!

// Pegadinha: off-by-one no for
for (int i = 0; i <= nomes.Length; i++) // ❌ estoura (vai até índice = length)
for (int i = 0; i < nomes.Length; i++)  // ✅
```
