# Lição 06.5: Segurança, Autenticação JWT e Autorização

Garantir que apenas usuários legítimos acessem os recursos corretos é indispensável em qualquer API conectada à internet. No ecossistema ASP.NET Core, a segurança baseia-se em dois conceitos complementares: **Autenticação** e **Autorização**.

---

## 1. Autenticação vs. Autorização

- **Autenticação (AuthN):** Responde à pergunta *"Quem é você?"*. É o processo de validar credenciais (ex: usuário e senha, certificado digital ou chave de API) e emitir uma identidade verificável.
- **Autorização (AuthZ):** Responde à pergunta *"O que você tem permissão para fazer?"*. Determina se a identidade autenticada possui os privilégios ou papéis (roles) necessários para acessar determinado endpoint.

---

## 2. A Estrutura de um Token JWT (JSON Web Token)

O JWT (RFC 7519) é um padrão aberto para transmissão compacta e autossuficiente de informações de segurança. Ele é composto por três partes separadas por pontos: `header.payload.signature`

1. **Header:** Metadados sobre o algoritmo de assinatura (ex: `HS256`, `RS256`) e o tipo de token.
2. **Payload (Claims):** Declarações sobre o sujeito da autenticação (ex: `sub`, `email`, `role`, `exp`). Não armazene senhas ou dados confidenciais aqui, pois o payload é apenas codificado em Base64URL e pode ser lido por qualquer pessoa.
3. **Signature:** Assinatura criptográfica calculada combinando o header, o payload e uma chave secreta. O servidor verifica a assinatura para garantir que o token não foi alterado por terceiros.

---

## 3. Gerando um Token JWT no C#

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;
using Microsoft.IdentityModel.Tokens;

public static class TokenService
{
    public static string GerarToken(string usuarioId, string email, string role, string chaveSecreta)
    {
        var tokenHandler = new JwtSecurityTokenHandler();
        byte[] chaveBytes = Encoding.UTF8.GetBytes(chaveSecreta);

        var tokenDescriptor = new SecurityTokenDescriptor
        {
            Subject = new ClaimsIdentity(
            [
                new Claim(ClaimTypes.NameIdentifier, usuarioId),
                new Claim(ClaimTypes.Email, email),
                new Claim(ClaimTypes.Role, role)
            ]),
            Expires = DateTime.UtcNow.AddHours(2),
            SigningCredentials = new SigningCredentials(
                new SymmetricSecurityKey(chaveBytes),
                SecurityAlgorithms.HmacSha256Signature)
        };

        SecurityToken token = tokenHandler.CreateToken(tokenDescriptor);
        return tokenHandler.WriteToken(token);
    }
}
```

## 4. Configurando a Validação JWT no Program.cs

No arquivo `Program.cs`, adicionamos os esquemas de autenticação e as regras de autorização:

```csharp
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;

var builder = WebApplication.CreateBuilder(args);

string chaveSecreta = builder.Configuration["Jwt:ChaveSecreta"]
    ?? "ChaveSuperSecretaComMaisDeTrintaEDoisCaracteres123!";

builder.Services
    .AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(opcoes =>
    {
        opcoes.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(chaveSecreta)),
            ValidateIssuer = false, // Em produção, valide o emissor real
            ValidateAudience = false,
            ClockSkew = TimeSpan.Zero // Sem tolerância extra de atraso de relógio
        };
    });

builder.Services.AddAuthorization(opcoes =>
{
    opcoes.AddPolicy("ApenasAdmin", policy => policy.RequireRole("Admin"));
});

var app = builder.Build();

app.UseAuthentication();
app.UseAuthorization();
```

## 5. Protegendo Endpoints nas Minimal APIs

Para exigir autenticação em rotas específicas, use `.RequireAuthorization()`:

```csharp
// Rota pública de login
app.MapPost("/api/v1/auth/login", (LoginDto login) =>
{
    if (login.Usuario == "admin" && login.Senha == "123456")
    {
        string token = TokenService.GerarToken("1", "admin@faculdade.com", "Admin", chaveSecreta);
        return TypedResults.Ok(new { token });
    }
    return TypedResults.Unauthorized();
});

// Rota protegida: exige token JWT válido
app.MapGet("/api/v1/relatorios/geral", () =>
{
    return TypedResults.Ok(new { mensagem = "Relatório confidencial processado." });
}).RequireAuthorization();

// Rota restrita a perfis com a role Admin
app.MapPost("/api/v1/cursos", CriarCursoHandler)
    .RequireAuthorization("ApenasAdmin");
```
