# Lição 06.2: Minimal APIs Modernas no .NET (Roteamento, Validação e OpenAPI)

As **Minimal APIs** foram introduzidas no .NET 6 e amadureceram como a forma primária recomendada para a construção de microsserviços e APIs web de alto desempenho no ecossistema .NET. Elas eliminam a sobrecarga cerimonial de Controllers clássicos, alcançam menor consumo de memória e inicialização acelerada.

---

## 1. Estrutura Básica de uma Minimal API

Em um único arquivo (`Program.cs`), configuramos os serviços e mapeamos os endpoints com sintaxe fluente e tipagem estrita:

```csharp
var builder = WebApplication.CreateBuilder(args);

// Registro de serviços
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

// Mapeamento de endpoints
app.MapGet("/api/v1/saudacao", () => "Olá, Minimal APIs!");

app.Run();
```

## 2. Injeção de Dependências e Parâmetros em Handlers

Os handlers das Minimal APIs inferem automaticamente de onde vêm os argumentos:

```csharp
app.MapPost("/api/v1/matriculas", async (
    NovaMatriculaDto dto,                           // Do corpo da requisição (JSON)
    IMatriculaService service,                     // Do container de Injeção de Dependência
    CancellationToken ct) =>                        // Token de cancelamento da requisição
{
    var matricula = await service.MatricularAlunoAsync(dto.AlunoId, dto.CursoId, ct);
    return TypedResults.Created($"/api/v1/matriculas/{matricula.Id}", matricula);
});
```

### Regras de Inferência de Parâmetros
1. Tipos complexos ou records sem atributos são lidos do **Body (JSON)**.
2. Nomes que coincidem com variáveis da rota (`/cursos/{id}`) vêm de **Route Values**.
3. Tipos primitivos não presentes na rota vêm de **Query String** (`?pagina=1&tamanho=10`).
4. Tipos registrados no `IServiceProvider` são resolvidos por **Injeção de Dependência**.
5. Headers específicos podem ser anotados com `[FromHeader]`.

## 3. Retornos Tipados com TypedResults

Prefira utilizar `TypedResults` em vez de `Results`. Ele fornece type-safety em tempo de compilação e gera automaticamente metadados OpenAPI precisos para o Swagger:

```csharp
app.MapGet("/api/v1/cursos/{id:int}", async Task<Results<Ok<CursoDto>, NotFound>> (
    int id,
    ICursoRepository repository,
    CancellationToken ct) =>
{
    var curso = await repository.ObterPorIdAsync(id, ct);
    if (curso is null)
    {
        return TypedResults.NotFound();
    }

    return TypedResults.Ok(new CursoDto(curso.Id, curso.Titulo, curso.PrecoBase));
});
```

## 4. Agrupamento de Rotas com MapGroup

Para APIs com múltiplos endpoints sobre o mesmo recurso, o método `MapGroup` permite modularizar rotas, aplicar prefixos comuns, tags de documentação e autorização:

```csharp
var grupoCursos = app.MapGroup("/api/v1/cursos")
    .WithTags("Cursos");

grupoCursos.MapGet("/", async (ICursoRepository repo) =>
    TypedResults.Ok(await repo.ListarTodosAsync()));

grupoCursos.MapGet("/{id:int}", async (int id, ICursoRepository repo) =>
{
    var curso = await repo.ObterPorIdAsync(id);
    return curso is not null ? TypedResults.Ok(curso) : TypedResults.NotFound();
});

grupoCursos.MapPost("/", async (CriarCursoDto dto, ICursoRepository repo) =>
{
    var novo = new Curso(0, dto.Titulo, dto.PrecoBase, dto.VagasTotais);
    await repo.AdicionarAsync(novo);
    return TypedResults.Created($"/api/v1/cursos/{novo.Id}", novo);
});
```

## 5. Filtros de Endpoint (Endpoint Filters)

Filtros de endpoint interceptam a execução antes ou depois do handler, sendo ideais para validação de dados, telemetria de latência e auditoria:

```csharp
public class ValidacaoCursoFilter : IEndpointFilter
{
    public async ValueTask<object?> InvokeAsync(EndpointFilterInvocationContext context, EndpointFilterDelegate next)
    {
        var dto = context.GetArgument<CriarCursoDto>(0);
        if (string.IsNullOrWhiteSpace(dto.Titulo))
        {
            return TypedResults.BadRequest("O título do curso é obrigatório.");
        }
        if (dto.PrecoBase < 0)
        {
            return TypedResults.BadRequest("O preço base não pode ser negativo.");
        }

        return await next(context);
    }
}

// Aplicando o filtro ao endpoint:
grupoCursos.MapPost("/", CriarCursoHandler)
    .AddEndpointFilter<ValidacaoCursoFilter>();
```
