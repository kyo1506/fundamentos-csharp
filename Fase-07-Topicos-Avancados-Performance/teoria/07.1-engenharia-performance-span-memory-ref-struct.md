# Lição 07.1: Engenharia de Performance, Zero-Allocation e Span<T>

Em sistemas que processam milhões de requisições por segundo ou analisam fluxos contínuos de dados (streaming de telemetria, parsing de logs, gateways financeiros), o tempo gasto pelo Garbage Collector alocando e desalocando pequenos objetos na memória torna-se o gargalo número um da CPU. A técnica central para eliminar essa sobrecarga chama-se **Zero-Allocation**.

---

## 1. O Problema das Substrings Clássicas

No C# tradicional, strings são imutáveis e residem no heap gerenciado. Ao extrair partes de um texto com `.Substring()` ou `.Split()`, uma nova string é alocada no heap para cada fragmento:

```csharp
// Abordagem Clássica (Gera pressão desnecessária no GC)
string log = "2026-10-04 10:15:30 [INFO] Aluno matriculado com sucesso";
string data = log.Substring(0, 10);     // Aloca nova string no heap
string nivel = log.Substring(20, 6);    // Aloca outra string no heap
```

Se processarmos 100.000 linhas de log por segundo, esse código gerará centenas de megabytes de lixo por segundo, disparando coletas de Gen 0 e Gen 1 constantes que paralisam threads de execução.

---

## 2. A Solução: Span<T> e ReadOnlySpan<T>

Introduzido para permitir representação segura de memória contígua em qualquer local (heap, stack ou memória nativa):

- `Span<T>`: Representa uma janela contígua de memória mutável.
- `ReadOnlySpan<T>`: Representa uma janela contígua de memória somente leitura (ideal para strings e buffers de entrada).

Ambos possuem custo de alocação **zero no heap**:

```csharp
// Abordagem Zero-Allocation com ReadOnlySpan<char>
ReadOnlySpan<char> logSpan = log.AsSpan();

// O método Slice cria uma "visão" (view) sobre os mesmos caracteres originais sem copiar nada
ReadOnlySpan<char> dataSpan = logSpan.Slice(0, 10);
ReadOnlySpan<char> nivelSpan = logSpan.Slice(20, 6);

// Conversão direta de span para número ou data sem criar string intermediária
int ano = int.Parse(dataSpan.Slice(0, 4));
```

---

## 3. O Que É uma ref struct?

`Span<T>` é declarado como uma `ref struct`:

```csharp
public readonly ref struct ReadOnlySpan<T> { ... }
```

Uma `ref struct` possui restrições estritas garantidas em tempo de compilação para assegurar que seus dados residam **exclusivamente na pilha de execução (stack)** e nunca escapem para o heap gerenciado:

### Regras de uma ref struct
1. **Não pode sofrer boxing:** Não pode ser convertida para `object` nem para interfaces comuns.
2. **Não pode ser campo de classes normais:** Só pode ser campo de outra `ref struct`.
3. **Não pode ser capturada em lambdas ou closures:** Não pode ser usada dentro de expressões anônimas assíncronas.
4. **Não pode cruzar instruções `await`:** Em métodos `async`, a máquina de estados move variáveis locais para o heap ao pausar. Por isso, um `Span<T>` não pode sobreviver entre um `await` e outro.

---

## 4. Para Cenários Assíncronos: Memory<T> e ReadOnlyMemory<T>

Quando você precisa passar um buffer fatiado através de fronteiras assíncronas (`await`), utilize `Memory<T>` ou `ReadOnlyMemory<T>`:

- `Memory<T>` é uma `struct` normal (não é `ref struct`), portanto pode ser armazenada no heap ou usada em métodos assíncronos.
- No momento exato em que for manipular os bytes em sincronia, obtenha o span correspondente chamando `.Span`:

```csharp
public async Task ProcessarBufferAsync(ReadOnlyMemory<byte> buffer, CancellationToken ct)
{
    // Passa de forma assíncrona com segurança
    await Task.Delay(50, ct);

    // Converte para Span local para leitura zero-allocation ultra-rápida
    ReadOnlySpan<byte> span = buffer.Span;
    byte primeiroByte = span[0];
}
```

## 5. Tabela Comparativa de Abstrações de Memória

| Abstração | Tipo | Onde Reside | Suporta async/await? | Alocação no Heap? |
|---|---|---|---|---|
| `string` / `T[]` | Classe (Reference) | Heap gerenciado | Sim | Sim |
| `Span<T>` | `ref struct` (Value) | Apenas na Stack | Não | Zero |
| `ReadOnlySpan<T>` | `ref struct` (Value) | Apenas na Stack | Não | Zero |
| `Memory<T>` | `struct` (Value) | Stack ou Heap | Sim | Zero (sobre array existente) |
| `ReadOnlyMemory<T>` | `struct` (Value) | Stack ou Heap | Sim | Zero (sobre array existente) |
